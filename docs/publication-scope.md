# Public source scope

This is a curated source export of version 0.27.2, database schema 29. It preserves the main local workbench, typed contracts, expression engine, persistent worker, saved-result/report/review lifecycle, dependency locks, selected tests, preparation tools, source-grounded material contracts, and finite operator-definition policies. It is not the separately accepted local Runtime archive. Source changes after that freeze are reviewed on a work branch; old runtime acceptance is not reused as a current CI result.

## Included

| Path | Purpose |
| --- | --- |
| `paper_alpha/` | Backend, factor/evaluation tools, persistence, recovery, and optional provider implementation |
| `frontend/src/` | React/TypeScript interface, generated API contracts, and frontend logic tests |
| `frontend/public/` | Decorative project-generated illustration and KaTeX license notice |
| `contracts/` | Versioned provider schemas, prompts, and policies required by the application |

| `tests/` | Representative expression, evaluation, formula, mutation, recovery, selected-span, formula-engineering, and finite definition regressions |
| `evaluation_suites/v05/material_confirmation.json` | Empty public fixture declaration; no personal user message or approval |
| Root dependency files | Installation metadata and exact dependency versions |

`SOURCE_MANIFEST.json` classifies and hashes every published file except itself. This supports byte inventory comparison; it is not a signed publisher attestation.

## Kept local

No databases, user research, actual experiment outputs, downloaded market data, external paper originals or full extractions, account material, secrets, native authorization, enabled provider configuration, environment directories, logs, historical validation records, or version backups are published. The original frozen packages and the installed service are separate local assets.

The Alpha101 PDF and full extracted JSON are produced only by the explicitly invoked preparation script from a user-supplied source document. Both are ignored by Git. The public vendor provenance omits the author's private local path while retaining original and adapted file hashes and the stated reuse changes. Public Alpha101 templates remove historical personal confirmations; no reader is recorded as having approved the research.

## Source-dependent optional paths

The default daily workflow and the original CLI demonstration are usable from this publication. Alpha101 browser import and paper-dependent tests require the documented local PDF preparation.

Monthly industry-portfolio, author-archive, semantic-review catalog, historical benchmarking, and native qualification paths also exist in the code. Their private historical material, method registries, evaluation catalogs, original datasets, and qualification evidence are not shipped. A clean clone does not preload those studies or satisfy their source/hash contracts. Missing resources remain explicit blockers; public preparation does not manufacture authority, replace scientific input, or rewrite the original identity checks.

Optional real App Server material extraction and candidate generation need current host configuration and qualification; no enabled configuration, credentials, or permission grant is included. Installing the package grants no real-model or reserved-data access. The public source includes the 119 current Native profile inputs and the new grounded-material/formula-engineering contract resources; source availability does not confer execution authorization.

## Publication test fixtures

The operator-definition public test file curates synthetic cases from the existing regression suite. Historical real-response and research-report fixtures are excluded. The public formula-engineering fixture supplies an original, complete named formula (`Alpha#9001: close`) so the stricter source-support gate reaches the intended scientific-unknown and disposition checks. Product validation rules and the original development tests are unchanged.

## Maintained export

The private development checkout and this public repository have separate Git histories. The public baseline was `90d658c73dbda40df7cd2db6f48e0a6a83dee0ef`. The maintained development-side exporter is `publications/export_public_source_current.py`, using `publications/public-source-policy.json`. It copies current application code, contracts, primary README/docs, selected public tests and original tutorials. A small maintained overlay holds ignore rules and the explicitly curated synthetic formula-engineering test. It regenerates `SOURCE_MANIFEST.json`; editing the old versioned export is not the release source of truth. Old frozen runtime packages and export snapshots are preserved.
