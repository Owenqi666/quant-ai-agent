# v0.9 优化计划、任务清单与 Agent 分工

起点：v0.8.0 / 3f58e9e395fe588df792eba7c5b6428ad80e93d6，2026-10-01 工作树干净。依据 `artifacts/project-flow-v08-01` 的现状核查。AI、RAG、BRAIN 保持关闭，基础前端不做视觉重设计。

## 评估与完整实施顺序

1. **P1 真实观测回流**：已有六阶段人工对照协议和审核计时，但空白观测模板不能导入、关联或统一分析。本轮完成严格输入、不可变保存、去重、结果绑定、明细与有条件的对照、导出及基础界面。真实观测仍由本人产生；自动化样本永远分开。
2. **P2 真实行情入口**：现有执行器明确只支持合成数据。先完成来源/授权声明、快照身份、字段/时间/复权/日历/股票池等约定的接入前检查；取得实际来源后，实施一个来源的转换适配、数据质量和时点验证，再评审执行器契约。不通过移除 synthetic 限制来冒充真实接入。
3. **P3 独立研究验证**：现有独立数值参考仅覆盖七个精确公式。先建立独立材料、人工预期、开发/保留分组与冻结摘要的准入规范；收到未参与开发的材料后按实际表达式扩充独立参考和负例。没有新材料时，不用 Alpha101 同源变体冒充独立保留样本。
4. **P4 最终测试流程**：在 P2/P3 条件确定后，实施研究协议冻结、候选提交、一次性评测与追加式审计。先明确状态机、幂等/失败恢复、数据泄漏边界及验收场景；当前 test 隔离锁保留，不开放普通执行接口的 test 参数。
5. **并行工程交付**：API 契约、版本化迁移、备份恢复、浏览器使用、可复现示例和统一验收。远端 CI 配置已存在，实际运行需仓库/权限；本地验收不写成远端通过。
6. **后续按需扩展**：BRAIN 人工交换桥接、AI/RAG 有出处草稿、单项研究复现包、多用户与策略成交模型。它们不阻塞本轮 P1。

## 本轮可交付范围

完成 P1 的完整前后端链路，并完成 P2/P3 的可执行接入前检查与 P4 设计规范。其余阶段的正式数据接入、独立研究结果和最终 test 发布取决于真实输入与冻结研究协议，在任务表中保留待输入状态。不得将检查工具完成写成真实研究已经完成。

## P1 正确性契约

- 沿用 v07 六阶段定义：reading / hypothesis / implementation / run_setup / review / report；主动、等待、离开分别记录。旧协议和空白模板保持原样。
- 未填写模板不能当已观测记录。区分 human 与 automation 来源；只是用户声明，不能冒称身份认证。自动化记录不进入人工完成率/时间收益。
- 不接受客户端汇总时间为计算结果；仅明确结束的区间产生时长。缺失与中断保留 null 和原因；未来时间、非法范围、跨阶段重叠或重复计时应拒绝/明确处理。
- 导入记录绑定协议摘要、参与者、条件、版本及输入身份；工作台结果绑定具体研究、修订、运行、尝试及审核。外部 CLI 路径只作声明引用，不任意读取服务器文件，也不冒称已核验。
- 复制审核计时后不得再叠加审核总时长。引用其他研究或其他结果的审核应拒绝；未测量阶段不能按零处理。
- 同键同正文返回同一记录；同键异正文冲突。记录内容与摘要不可变，保留未完成/失败尝试。列表有资源边界，导出核对摘要。
- 仅对符合相同协议、输入、版本、参与者和环境约定的非练习记录形成有说明的个案对照；不合条件返回原因。保留原始记录、分母、部分覆盖和学习效应，不能推断普遍效率提升。
- 保存前耐久记录原请求；未知提交结果用原键确认。保存成功与列表刷新失败分别显示；切换任务不让迟到响应覆盖新选择。
