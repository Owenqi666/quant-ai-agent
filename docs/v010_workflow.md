# v0.10：日常研究与可选人工对照

日常使用不需要观测 JSON、计时、内部 ID 或人工对照。AI 仍未启用；候选由本人编辑或使用已有模板，合成计算指标由引擎生成。

## 日常研究

1. 在「切换研究」选择已有研究，或新建研究并选择论文与数据。
2. 核对证据、假设和候选；需要修改时保存为新修订。研究版本与当前所选实验使用的版本分开显示。
3. 提交实验并查看结果。失败时保留原因和尝试，再决定是否修订；完成不等于所有候选有效。
4. 从当前结果进入审核，填写一次实际判断。人工计时可选，未计时不阻止研究或审核。
5. 从当前结果进入报告，确认这一项实验后生成冻结报告并下载。多实验对比和总结仍可从高级入口使用。

输入、数据、配置、运行结果、失败和审核继续保留。查看页面、进入报告入口或读取预填信息均不会自动创建观测、审核或报告。

### v0.10.1：看着实际输出审核

在「审核结果」选择实验和候选后，同页左侧显示这次实验的声明公式、实际执行公式、引用原文与页码、假设和经济解释归因，以及计算工具产生的指标；右侧填写判断。页面始终读取所选实验的冻结任务，研究后来修改不会替换旧结果的依据。

平均 Rank IC、平均日毛收益、有效评估天数和因子覆盖率分别展示含义，缺失指标显示未计算。可以下载该候选的因子 CSV、结果 JSON 和对应执行尝试的报告；缺失和失败保留原因与执行记录。完整性校验失败或缺少审核目标时隐藏指标和下载入口，已有待确认审核仍可恢复。

当前合成数据的正负收益不构成接受或拒绝实现的自动阈值。审核应依据引用是否准确、声明公式与执行是否一致、经济解释是否正确归因、字段与时间条件是否符合研究要求；没有证据的维度保留未评定。文件完整性校验通过也不等于这些研究判断通过。

本补丁只修改审核展示、前端类型和版本标识；验证包括前端单测、实际浏览器的候选切换/旧实验/失效输出/下载关联、既有审核恢复场景、API 契约和独立源码包检查。未改变计算引擎、数据或数据库 schema；实际结果保存在 artifacts/release-v0101-*，不冒用 v0.10.0 的统一验收作为本补丁全量测试。

## 需要测量流程时再开启

「流程观测」是可选工具。普通操作使用引导表单，旧 JSON 文件可通过高级导入处理。

先选择路径并填写一次共同条件，明确本人来源和是否为练习，再开始记录。通过阶段、等待、离开和暂停按钮记录实际工作；跨页面时紧凑记录条保留。切换页面不会推断研究阶段，离开浏览器也不会自动算作离开工作，因为可能正在阅读 PDF 或使用终端。

结束后选择实际实验/尝试及本人的审核，系统关联内部 ID、摘要、核验和报告引用，并复用已保存的五维判断。CLI 外部产物仍需本人提供真实引用及判断，服务不会读取任意路径来冒充核验。记录明确完成、未完成或放弃，核对预检后再保存。

两条路径共享条件可明确复用；实际差异保留，不能为了形成时间差而覆盖。协议仍只适用于现有单候选 Alpha101，默认多候选示例会显示不兼容原因。练习和自动化记录不进入人工对照。

## 恢复与来源

本机草稿和提交前的原请求均保留。正常暂停后可恢复；刷新或切研究时仍开放的计时区间标为中断，不能用重新打开时间补结束。本轮沿用旧协议：中断会话先结束为未完成记录，后续另开会话，避免未知结束区间与后续时间重叠。

收到提交响应前断网时，以原请求安全重试，不创建新会话伪装为另一份观测。原始高级导入和冻结导出继续可用。

协议和可核验的运行元数据由服务提供。新版独立源码包从本机构建记录取得提交号，前提是清单内文件全部匹配且没有额外 Python 模块；这是本机文件一致性检查，不是签名或远端 Git 认证。旧包或开发中源码无法确认提交时留白，允许一次声明；不向上搜索宿主仓库。服务环境不认证人工设备或外部 CLI 环境。

## 开发与交付

沿用 README 启动命令。自建开发工作区可用：

```sh
.venv/bin/python -m paper_alpha.server.launcher --home var/my-v010-workspace --port 8766
```

schema 仍为 7。旧工作区、冻结协议和观测不会被改写；本轮 schema 不变，正式预览先离线备份，再用验收包在原工作区路径启动，保留工作区身份和浏览器草稿作用域；旧源码包和备份保留。交付结果以对应 `artifacts/release-v010-*` 的记录为准。
