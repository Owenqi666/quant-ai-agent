# v0.14 月度实验执行链路

月度实验使用独立的数据库记录、冻结输入和工作流。它不创建旧日度 Task，也不把日总收益夹具转换成 OHLCV。`monthly_experiments`、`monthly_attempts`、`monthly_events`、`monthly_reviews`、`monthly_reports` 和 `monthly_receipts` 由 schema 10 一次迁移创建，旧实验行保持原样。

创建时，服务核验已保存规则的 ID 和摘要，使用服务器生成的受控夹具，冻结完整协议、月度配置和输入。规范输入保存在数据库中，单份最多 64 MiB；每次尝试另有可独立检查的输入文件。这是当前有界的重复存储，尚未引入共享内容对象或垃圾回收。创建请求使用幂等键，同键同正文回放原确认，同键不同正文返回 409。

领取先在短事务中登记准确的 worker、尝试 ID、尝试次数及 preparing 阶段，然后才创建目录和写入输入。目录结构由安全 UUID 派生为 `monthly/<experiment>/attempts/<attempt>/`，数据库不存绝对路径。输入准备失败会留下可追踪的失败尝试；进程中断留下的部分文件归属于原尝试，不通过文件存在与否推断成功。

现有单 worker 在日度和月度队列间轮转，各队列内部仍按创建顺序执行。一类为空时处理另一类。`--once` 最多处理一个排队任务，输入准备失败也算本次处理，避免意外继续执行另一类任务。月度子进程运行独立的 `paper_alpha.monthly_workflow`，继承相同的 worker 锁文件描述符。监督进程死亡但计算子进程仍存活时，新 worker 和离线备份仍被锁阻止。

准备、执行、核验和发布都有阶段记录。后台心跳仅更新 worker 健康及准确活动尝试的心跳；心跳失效本身不授予另一个 worker 接管权。worker 在成功持有进程锁后才恢复两类遗留活动任务：原 running 变 interrupted，原 cancelling 变 cancelled。恢复不自动重算，也不将已落盘但未发布的结果认作成功。

输出完整核验、独立参考检查和结果读取在数据库写锁外进行。发表前再次核对 worker/实验/尝试身份、冻结输入及输出文件的 stat 清单，包括 inode、ctime 和 mtime；普通文件修改、链接替换和清单变化会拒绝发布。此处仍有短时间的目录/stat 检查在写事务中，未声称完全没有文件系统操作。后续完整读取继续核验摘要，不以缓存指标掩盖损坏。

生命周期的 completed 表示工作流完成。论文模式仍可以得到 blocked 的研究结果，独立参考检查相应为不支持；界面必须保留这层区别。非 blocked 结果必须有通过的独立参考检查。所有数字都来自受控夹具，不代表真实市场表现或论文原式复现。

取消绑定确切尝试，旧页面的目标不同返回 412。终态取消不更改已有结果。只有 failed、interrupted、cancelled 可以显式重试，每个实验最多三次尝试。排队阶段直接取消没有尝试 ID，需要使用新幂等键新建实验；它不伪造一个尝试用于重试。重试收据在随后运行期间仍回放原确认，旧 worker 永远不能发表新尝试的结果。

详情读取完整核验文件；损坏返回 409。轻量状态接口返回 `change_token`，明确 `integrity_checked=false`，不执行重新核验。审核和报告都绑定确切尝试及结果摘要，发表前复核文件与数据库快照。审核来源由调用方声明为 human 或 automation，服务不把自动测试写成人工评价。

报告包含冻结结果、协议和当时的审核列表，Markdown 只格式化已有指标。后来新增审核不会改写旧报告。读取已冻结报告核验报告自身及其结果摘要，保持历史快照可读；它不声称当前源文件仍完好。发起新审核或新报告仍需原实验文件通过完整核验。审核、报告及请求收据在同一事务提交，响应丢失后的重试不会重复创建。

离线备份会包含独立月度目录和新数据库表。由于没有绝对路径列，恢复到新目录不会改写月度输入、结果、审核和报告摘要。

专项测试：

```sh
.venv/bin/python -m unittest tests.test_monthly_experiments tests.test_monthly_runner -v
```

测试在临时工作区覆盖真实子进程、日度/月度轮转、单次模式、持续准备心跳、取消与关闭、杀死监督进程后子进程继续持锁、显式恢复重试、陈旧 worker 拒绝发布、发布前篡改、请求原子提交、冻结报告、损坏拒绝以及备份恢复。已有 `tests.test_runner` 与 `tests.test_worker_integration` 保留日度兼容验证。
