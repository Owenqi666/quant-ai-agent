# v0.13 研究规则保存

研究规则是独立资源，不会创建或修改旧的日度 Task、实验、审核、回归记录或输出文件。保存只表示一份规则定义被记录；不能据此宣称已复现论文结果、运行真实行情回测或得到投资收益。

`ResearchProtocols(store)` 提供 `create(title, note, config, parent_id=None)`、`get(id)` 和 `list(limit=20, offset=0)`。主服务负责 schema 9 的 `research_protocols` 表迁移和 HTTP 接口，模块使用现有 SQLite 连接与事务实现。

每条记录的正文包含规范配置、配置摘要、标题、备注、父版本、逐字段变更、计算语义版本和服务器提供的来源及未决事项。正文摘要决定 `protocol_<sha256>` 身份；创建时间不参与正文身份。同正文重试和并发保存返回原记录及原时间，不增加另一条记录。调用方不提供来源字段，服务器从对应模式的预设复制来源说明。

修改参数或从论文模式转为项目约定会形成新正文及新身份。派生记录的 `changes` 与父配置比较；无父记录的根版本与对应模式的服务器默认配置比较。论文模式只能保存核心验证器认可的未决配置，不能静默填入项目选择的 ID 或缺失规则。接口不提供修改或删除操作；数据库外键也阻止删除被引用的父记录。

读取在同一 SQLite 读快照中验证正文、配置及身份摘要、字段结构、语义版本、父链和变更清单。读取保留原来的来源快照，不用当前服务器的来源文字覆盖它。后续若修改预设的配置定义，需要新的语义版本及明确的兼容读取实现；不支持的版本会返回冲突错误。内容摘要用于检测与固定身份不一致的损坏，不是用户认证或数字签名；创建时间本身不属于内容摘要。

边界明确限制为标题去首尾空白后 1–200 个字符、备注最多 4000 个字符、单条正文最多 64 KiB、父链最多 128 条。列表每页 1–100 条、偏移最多 100000；一次请求最多验证 512 条不同记录，超过则明确返回 413，不返回被截断的部分结果。无记录返回 404，输入错误返回 422，存储完整性问题返回 409。分页在一次请求内保持一致，独立分页请求之间仍可能插入新记录，排序使用创建时间和身份两个字段稳定处理并列时间。

创建操作在一个写事务内读取有界父链、计算小型 JSON 摘要并插入一条记录，没有论文读取、行情复制、因子运算或文件核验。列表及详情均为读事务，数量和页内记录共享同一快照。

服务验收命令：

```sh
.venv/bin/python -m unittest tests.test_research_protocols_service -v
```

测试使用临时工作区，覆盖丢失响应后的重放、并发去重、原文转项目及逐字段差异、来源快照保持、非法输入、正文/父记录篡改、重新计算摘要但结构或语义不合法的记录、外键与断链、并发修改时的读快照、分页与父链上限，以及旧业务行和文件不变。
