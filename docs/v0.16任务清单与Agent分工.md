# v0.16 研究准入、证据关联和审核回流

## 目标与现状

把已下载的 Goyal/Jegadeesh/Subrahmanyam 作者公开数据接入一个可完成、可阻断、可修订的研究任务。先判断数据能否支持声明的任务，再决定下一步，不通过缩短窗口、填缺失或挑选有未来收益的资产制造可执行结果。

v0.15 已有固定 V2 文件校验、原行面板、单月诊断、不可变保存和基础页面；四个检查月不能代表整个开发区间。v0.14 月度实验只接受日频受控夹具。现有 research_protocol 定义日频 ID，不适合作为预计算 DGW 的配置。本轮保持这些历史契约不变。

## 实施顺序与完成标准

1. **先冻结计划和契约。** 新增独立作者研究准入计划；固定论文证据、来源和窗口，声明开发区间、保留区间、任务字段要求、最低资产数及理由。下述示例在扫描前落盘。任何变化生成新计划摘要。
2. **全原行扫描。** 在声明区间内逐月扫描全部原始资产行，分别统计 MOM、MOM+DGW、MOM+MV、MOM+DGW+MV。历史不完整、非法和数值不可表示分别计数。目标月标签不参与扫描结果；后续月份按自己的历史窗口计算。
3. **关联研究记录。** 论文依据 → 项目计划及摘要 → 固定数据源 → 逐月资格及筛查决定 → 审核 → 修订。复用已有作者面板作为可选逐行证据，同源且月份落在开发区间内。不能把日频协议冒充作者方法。
4. **最小审核回流。** 审核绑定准确研究 ID 和摘要，明确人工或自动化来源；新版本可关联触发它的旧审核，保存变化，旧审核不会成为新结果的审核。
5. **交叉审查和交付。** 独立标量参考、未来标签扰动、边界和篡改测试；实际源复算；CLI/HTTP 决策一致；基础浏览器流程；完整发布验收、独立安装、备份恢复及运行工作区迁移。

本轮终态是“筛查完成：达到声明的数量门槛”或“筛查完成：未达到门槛”。两者都是有效的工程结果。数量达标仍不等于组合可执行。

## 本轮实际研究计划

- 数据：已下载且固定摘要的 IntnlData.mat、USData.mat，Harvard Dataverse V2；保留公开扰动/随机删除声明。
- 开发区间：1993-03 至 2006-12，共166个月；从作者样本起点开始连续扫描，不根据结果选月。
- 保留区间起点：2007-01。本轮不计算该区间的组合或绩效。之前已做全字段质量审计及少量检查月诊断，因此不宣称这是从未观察过的数据。
- 四个预先声明的计划：两份数据各有 MOM-only（项目筛查门槛30）和 MOM+DGW+MV（450）计划。
- 30 是为后续方法设计设置的项目筛查阈值，并非论文规则或统计充分性证明；450 是作者 Table8 初始九组×50的必要数量条件，本轮在未实施其他原文过滤之前检查，因此只能作上界筛查。
- 不运行收益组合。Table8 的国家/REIT/微盘过滤、组内数量、极值处理、中性化、权重和标签缺失处理尚未被本路径实现。下一轮应据本轮结果选定普通 MOM 项目方法或保持阻断，不能静默套用 v0.14。

先发布 docs/v016_author_study_contract.md；各 Agent 按同一契约工作，不自行扩大接口。生成的 OpenAPI/TypeScript 由主协调统一更新。Agent 完成后换方向只读交叉审查，发现问题由各自所有者修复。

## 具体验收矩阵

- [ ] 完整、缺历史、非法收益、DGW缺失、MV零值、数值溢出：四种资格与独立参考一致。
- [ ] 原行无遗漏/重复；分块结果不变；月份连续且不能越过保留边界；不静默截短。
- [ ] 改动目标月收益不改变该月资格；改动以后月份不改变此前资格。
- [ ] 区分源文件复算与聚合输入一致性检查；HTTP不认证未读取的原MAT。
- [ ] 同输入 CLI 和 HTTP 结果/报告一致；计数或摘要/收据篡改拒绝。
- [ ] 正确的筛查阻断可保存、查看、审核；新版本与旧审核可追溯且不继承通过。
- [ ] 断线重放不重复创建；父链有界；关联面板必须同源、同区间。
- [ ] 四份实际计划在源扫描前冻结；实际源两次扫描一致；报告只引用工具结果。
- [ ] 完整测试、独立源码安装、备份迁移、旧记录/文件保全和运行版本身份核验。

## 不包含与成果边界

AI/RAG、BRAIN自动化、通用数据格式、新论文检索、整体UI重设计继续后置。本轮不生成投资绩效，也不声称复现论文或测得人工效率提升。自动化演示审核必须标记 automation。人工比较、未扰动行情和最终测试执行仍待补齐。
