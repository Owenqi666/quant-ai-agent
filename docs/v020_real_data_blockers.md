# v0.20 Momentum 真实数据阻断复核

日期：2026-10-05。本轮沿用已部署 v0.20 的工程链路，只读检查论文、作者代码、冻结研究产物和一份有界原文件切片；未修改方法、门槛、业务数据或服务，未重跑 166 个月全扫描，未产生收益或人工审核结果。

## 结论

当前最直接的阻断是：**同一公开作者包在固定开发区间内，能完成 11 个月 MOM 历史的原资产行很少，无法达到预声明的每月 30 行项目门槛。** 文件已接入，月份轴连续，扫描没有被前 128 行的面板限制截断。该结论不证明 MOM 无法计算、不证明策略无效，也不意味着论文要求至少 30 行。

还存在两个独立阻断：原 DGW 的日频构造与缺失规则未确定；作者的股票池、过滤、排序、权重和收益标签方法没有接成可运行的真实来源组合实验。即使将某个月的数量条件解决，现有研究绑定也不会自动获得执行权限。

审查产物位于 [artifacts/v020-momentum-blocker-audit-01](../artifacts/v020-momentum-blocker-audit-01/)。其中 `frozen_count_analysis.json` 是**旧扫描结果的当次算术复核**，`bounded_source_check.json` 才是本次原 MAT 字节、元数据与小切片检查；两者不可混称一次新的全源计算。

## 0/166 的具体原因

冻结计划来自 `artifacts/author-studies-v016-01/intnl-mom/plan.json`：源为固定 Dataverse V2 `IntnlData.mat`；开发区间 1993-03 至 2006-12，连续 166 月；保留边界 2007-01；任务 `momentum`，不要求 DGW 或市值；门槛为项目声明的每月 30 个原资产行。

| 检查 | 复核结果及含义 |
|---|---|
| 是否读到了所有原行 | 旧扫描每月八类 mask 的总和都等于 59,367；不是最多 512 行的导出面板统计 |
| MOM-only 是否额外受 DGW / MV 筛选 | 否。mask 中 MOM 为 bit 1，selected 为所有包含 bit 1 的计数之和；DGW / MV 是否可用不改变该计划的 selected |
| 历史完整性为何失败 | 9,854,922 个“原资产行×目标月”观察中，2,147 个有可用 MOM；9,852,775 个至少一个历史收益非有限；完整但收益低于 −1、或数值不可表示的计数均为 0。这里不是独立资产数量 |
| 各月可用 MOM | 最少 2 行，1993-03；最多 26 行，2005-06；每个月均小于 30，故 0/166 |
| DGW / MV 本身是否整个缺失 | 否。旧扫描中每月独立可用 DGW 为 7,287–17,369 行，正有限 MV 为 7,486–18,210 行；与完整 MOM 同时可用的三者交集仅 1–13 行 |
| 是否缺了时间轴月份 | 否。固定源为 1989-01 至 2020-12，共 384 个连续月；缺的是资产字段值，不是自然月份索引 |
| 是否工具执行失败 | 否。终态为 `screen_blocked`，输入、计数、来源和原因均已保存，没有组合实验 |

历史全源质量报告没有发现三个核心字段的正负无穷。扫描代码中的 `momentum_missing` 严格表示“11 项中有非有限值”；不能从这一计数进一步拆出随机删除、上市/退市区间、源数据库空值各占多少。论文明确公开数据经扰动及随机删减，但并未提供可据此恢复原值的逐条原因表。

另外三份冻结计划的当次文件/聚合复验也通过：Intnl MOM+DGW+MV 为每月 1–13 行；US MOM 为 0–8 行；US MOM+DGW+MV 为 0–5 行。三者仍是历史扫描数字，本次未重新访问这些全区间字段。

本次有界检查重新验证 Intnl 固定文件 SHA256 / MD5 / 字节数与 HDF 元数据，只读原行 1–128 的 11 个月 Return 和 H−1 的 DGW / MV。目标 1993-03 时，每个历史月各有 12–18 个有限 Return，但同一原行连续 11 月全部有限的数量为 0；这与旧面板对应切片逐值一致。单月有值不等于完整窗口有值，此小切片只能验证局部对齐，不能独立证明全 59,367 行计数。

## 字段、窗口和规则的来源

令 H 为目标收益月。作者 MATLAB 使用 N×T，HDF 使用 T×N；现有适配明确按时间轴读取，没有把两个轴混用。

| 内容 | 当前规则 | 依据 / 归属 |
|---|---|---|
| MOM | `prod(1 + Return[H−12..H−2]) − 1`，11 个自然月，跳过 H−1 | 固定 PDF p.4、p.24；`SetupDataA.m:8–11` 与 `Table8A.m:11–19`。论文规则，不能为了提高覆盖率静默改短 |
| MOM 缺失 | 十一项全部有限、收益不低于 −1、结果可表示；不填补、不跨过缺月压缩窗口 | 项目明确声明的筛查契约。作者 `prod` 未指定忽略 NaN，且随后检查有限性；因此缺一个月后跳过它再复合也不是当前作者代码的 MOM |
| DGW | 读取 H−1 的预计算字段，筛查有限且位于 [−1,1] | 列对齐有作者代码依据；内部日频窗口、日缺值分母和最少有效日数仍未确认。字段存在不等于能独立重建 |
| ID 符号 | 作者 `XVARS(:,:,5) = -DGW`，Table8 使用 −ID 的排序方向 | `SetupDataA.m:28`。以后生成候选时必须区分原 DGW 和取负后的 X，不能把它们默认视为同方向 |
| 市值 | H−1 原 MV；筛查必须为有限正数；作者排序使用其 log，组合权重使用原尺度 | `Table8A.m:1–2,14,27,59–65`。零值保留在读取结果中，但不能作为正市值资格 |
| 收益标签 | 资格扫描不读取 H 的 Return；H 只供后续持有期评估 | 作者 `Table8A.m:23` 对应目标 H；项目排除未来标签反向选样本 |
| 30 行门槛 | 所有 166 个开发月都必须达到 | 冻结 `plan.rationale` 的项目筛查选择；不是论文门槛、统计功效判断或投资组合充分性证明 |
| 450 行门槛 | Table8 的 3×3 个格子×每格至少 50 行，只是初始必要数量条件 | 作者 `Table8A.m:3,15–19,57–65`；仍有股票池、格子和标签约束。不能从“达到 450”直接推导组合可评估 |
| 开发 / 保留边界 | 1993-03..2006-12 / 2007-01 起 | 项目冻结计划。旧全源质量审计已观察过后段，不应称为完全未见的最终测试集 |

具体对齐例：H=1993-03 时，Return 历史是 1992-03..1993-01；1993-02 为跳过月，也是 DGW / MV 的取值月。旧报告中 Intnl 1989 年等早期全空字段不直接落在此首个开发窗口内，不能用它们单独解释当前 0/166。

## 四类缺口应分开处理

| 分类 | 已确定的事实 | 仍缺什么 / 影响 |
|---|---|---|
| 实际数据覆盖与扰动 | 作者 MAT 已下载并有固定来源摘要；Return 稀疏，完整 MOM 窗口很少；原行匿名 | 无法恢复删除值、原证券身份、上市/退市缺失原因和未扰动行情。公开包不能当作商业原库的市场收益验证，也不能以论文名称替代具体数据条件 |
| 项目研究选择 | 完整历史、不填补、月度门槛 30、固定 166 月和保留边界已声明 | 如果目标改为小样本方法演示，必须单独论证、另存计划并审核；不得事后降低原门槛或仅保留较完整月份来宣布原计划通过 |
| 作者方法未决 / 未接通 | MOM 月窗口、DGW 列位置、Table8 排序和若干处理可从本地 PDF / MATLAB 读出 | DGW 日频构造未确认；具体股票池资格、REIT / 微盘处理、极值处理、中性化、并列值、独立 / 顺序排序及月度持有方法尚未形成完整执行合同。Table8 的有效未来收益筛选后权重归一，与项目夹具严格持有期覆盖口径不同 |
| 适配与执行实现限制 | 现有 adapter 固定支持两个源；面板≤512 原行；全源准入扫描另有分块路径；版本和来源可追溯 | 作者源路径目前只做面板 / 准入诊断，不把它当日频行情或转换成可交易证券；已有月度计算是受控夹具路径，不能直接替代作者 Table8 或真实来源实验。研究绑定沿用整体 MOM / ID 协议，MOM-only 研究范围尚未独立接成执行路径 |

两项容易误读的状态也需要保留区别：

- `docs/research/momentum_sources.json` 的 `large_mat_files_downloaded=false` 是 2026-10-02 初始获取阶段的历史快照；后续固定 MAT、作者源审计与 v0.20 来源收据证明已经接入。它不能作为当前文件不存在的证据。本轮不改这一已被摘要绑定的历史清单。
- 旧面板 `formation_ready` 要求 MOM+DGW+MV 同时可用；MOM-only study 的 `selected_ready` 只要求 MOM。1993-03 的全原行三者交集为 1，MOM-only 为 2；切片 1–128 为 0。三种数字的样本和资格不同，并不矛盾。

## 版本与本次核验边界

Dataverse `2.0` 是**外部文件版本**；`gjs-v2-monthly-panel-v1` 是**适配器契约**；`gjs-v2-alignment-diagnostic-v1` 是**面板诊断语义**；`gjs-author-eligibility-v1` 是**全原行准入语义**；`gjs-rof-2025-eligibility-evidence-v1` 是**证据版本**；`gjs-research-binding-v1` 是**跨模块绑定合同**。不能因其中包含 v2 或 v1 就认为扫描发生了升级或数据变完整。

本次复验四份旧 study 的文件摘要、计划、全部月序列、mask 分区、结果与报告一致性，均通过。当前 `eligibility.py`、`eligibility_archive.py`、`eligibility_schema.py`、`eligibility_workflow.py` 与 intnl-mom 保存的代码快照逐文件 SHA256 相同，没有发现解释该 0/166 的版本漂移、窗口错位或 mask 筛选错误；这不是对所有代码错误的排除证明。

`artifacts/v020-author-source-01/attempt-02/local-source-receipt.json` 记录准备时原 MAT 核验通过、旧准入产物核验通过、**没有重算准入扫描**。本轮再次核对该准备包清单中的八个文件摘要及它与原 plan / input / result / source 的关联，不打开该包数据库、不通过服务重新导入。绑定仍为 blocked，`execution_ready=false`；关联的诊断作业 / Case 只是外部收据中的准确关联，没有组合收益。

## 下一步有限研究操作

1. **先完成当前 Alpha101 人工审核。** 本轮其他工作包正在准备准确材料与结论草稿。工具负责来源、指标定位和保存；本人负责原文是否支持结论及结果是否值得接受。Momentum 不妨碍完成这项现有工程评测。
2. **冻结 Momentum 的研究目标。** 工具可从已有 PDF / 作者代码整理“已知 MOM-only”和“完整 MOM+ID/Table8”两份方法差异说明，沿用现有证据与冻结模型；本人确定接下来研究哪一种。已知 MOM 月窗口不需要重新猜选，但若要偏离它，必须标为项目修改。DGW 未决规则不应被冒充为已知 MOM 公式本身的未知项。
3. **按选定目标补齐一份方法合同，而非先追求收益图。** 已明确的作者规则由工具定位和移植，未知规则继续保留空值；本人批准项目自主选择的股票池、门槛、窗口、缺值和持有口径。若只是研究小样本演示，其新计划必须明确样本、目的和不支持的统计 / 市场结论，原 30 行计划保持 blocked。
4. **只有在具体来源和方法均满足条件时再接组合实验。** MOM-only 至少需要符合声明的完整月收益、稳定资产身份及所选权重 / 股票池字段；若重新构建 DGW，还需要每日收益、交易日历和确认的窗口 / 缺值规则。完整论文行情研究还须记录许可、公司行动、退市 / 历史成员资格和字段取值时点。工具能验证所提供来源，不能通过公开包或论文标题替用户确认这些未提供条件。本轮不另找数据源。

本次研究审查的验收终点是：旧计数与正确窗口有可检查证据；阻断按四类分开；原计划未改变；下一项研究范围明确且未决规则仍阻断。**同一来源、同一计划无需再重复扫 166 月。** 当前工程准备可继续，新的真实来源组合评估应等待方法及具体数据条件确立，不能将合成月度夹具或少量匿名行的曲线当成论文复现。
