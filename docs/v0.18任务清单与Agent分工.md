# v0.18：AI 接入前的研究执行与验收链

日期：2026-10-05（Europe/London）。基线：v0.17.0 / schema13 / 8da21e5。审核依据：artifacts/pre-ai-audit-20261005-01/result.json。

## 本轮目标

复用现有因子引擎、研究版本、队列、审核、结果核验和工具预算，把一次受控研究从候选草稿推进到可审核结果，并修复跨修订时间隔离。模型提供商仍留白，UI 沿用基础设计。首个成功例采用已有 Alpha101 合成数据；Momentum 已有作者准入阻断作为停止案例，不生成不存在的作者组合收益。

1. 冻结 docs/v018_research_contract.md 中的方法、权限、状态和数据结构；保存原漏洞的纯内存复现。

7. 保存不可覆盖交付记录及操作说明，列明人工语义标签、真实来源和实际模型评测的剩余边界。

## 验收细则

- 时间保护覆盖 train 与 validation 的数据暴露范围（含预热），不只检查 validation 标签；原 test 不因改名或换修订变成未保护区间。
- 历史任务/结果不重写。迁移记录历史已声明区间和潜在暴露，遇到历史冲突保留并明示，禁止制造“从未看过”的声明。
- 执行任务从现有 paper/dataset 和人工维护的结构化候选开始，任务和每次草稿、校验失败、修订、提交、结果均有身份和日志。支持未知论文的人工结构化输入，不声称通用论文理解。
- 自动化实验仅由用户显式创建的任务授权；固定数据、论文、预算和开发边界，不能写人工审核、提高自身预算、改数据或开放 final test。
- 调度器使用现有字段/算子检查和计算引擎，校验与数值计算不能由模拟模型伪造。恢复保持原提交键；不能重复创建修订或实验。
- 结论中可以人工/模型声明解释，但可信数值仅由结果引用读取；正确证据 ID 不被自动当作语义正确。文档伪指令作为不可信内容，不改变工具权限。
- 语义材料提供原文、引用定位、参考判断草稿、五维标注模板及确认入口。已有用户确认“使用过 Alpha101”不等于对所有解释的人工标签；没有直接确认的项保持 pending，不能填造人工评分或时间收益。
- AI token/供应商费用不填模拟成绩；本轮只验证 provider-free 调度，未来接入真实 API 时再记录模型/提示词版本、原始响应、token、费用、网络错误和同任务成绩。

## 本轮完成的准确边界

有限 Alpha101 研究任务、时间保护、受控执行、审核回流与结构化结论可以完成。真实行情适配、作者完整 Momentum 方法、最终市场测试、用户亲自确认的语义标签、实际 AI 效果、BRAIN 自动化和 UI 设计继续分别记录，不以软件通过代替研究成果。完成状态以新交付记录为准；本文件保留开工范围。
