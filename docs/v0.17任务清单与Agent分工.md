# v0.17：研究任务关联与受限工具链

## 目标与基线

基线为已验收 v0.16.0（67c9a1b，schema12）。本轮将已经存在的 Alpha101、受控月度实验、作者数据准入纳入共同的任务查看与决策流程。AI 提供商仍不接入，前端沿用基础样式。现有计算内核、来源核验和审核修订服务继续复用。

完整性评估的主要结论是：工程基础已较成熟；研究产物分散；缺少面向模型的权限和调用契约；工程评测尚不能证明研究语义忠实性。作者源组合执行、完整 Table8、未扰动市场数据、最终市场测试仍是独立研究目标。本轮不会将受控收益结果归到作者源，也不会为了准入通过调低既定门槛。

## 本轮可交付范围

1. 新增轻量研究任务（ResearchCase），引用已核验的 daily run、monthly experiment 或 author study，并冻结具体结果身份与上下文。保留三个领域的数据和方法差异。
2. 任务展示论文/证据、研究定义或项目约定、数据与代码/配置来源、结果、现有审核及明确的阻塞原因/允许下一步。不复制或继承人工批准。
3. 新增受限工具会话：只能读取任务和证据、读取确定性计算产物、提出待审核的下一步建议。模型接口留白；不暴露导入 scan、填写计算指标、写人工审核、修改门槛、解锁最终测试或执行任意代码的工具。
4. 调用输入与响应结构化，累计调用/错误重试/耗时预算持久化，幂等键重放不重复执行。会话与工具产物可追溯，重新启动后预算不重置。
5. 以脚本策略跑通成功与阻断案例，建立固定规则/行为对照评测及待人工确认的语义评测材料。明确区分规则预期、来源支持和人工确认，不能制造人工标签或时间节省数字。
6. 基础页面提供任务上下文、工具诊断、建议与记录；既有人工操作通过明确入口继续完成。发布检查、备份迁移与运行版本更新沿用已有流程。

这是一条限定范围的研究诊断与提案链。若后续允许 AI 自动生成新假设或推进 Momentum 收益实验，仍须补作者月度输入到组合方法的适配，以及研究系列级最终测试控制。

## 验收边界

成功案例证明既有计算结果能够通过统一研究入口得到检查与建议；作者数据阻断案例证明系统正确停止。二者不能相互代替数据源。固定脚本与工作台共享引擎属于集成对照，数值正确性继续依赖已有独立数值测试。新规则案例不是人工语义审核，不声称 LLM 收益、实际人工提效、投资收益或完整论文复现。

最终完成情况以新的不可覆盖交付记录和测试产物为准；此文件保存开工范围。
