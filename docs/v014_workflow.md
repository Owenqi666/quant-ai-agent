# v0.14 月度实验操作与边界

此版本把已保存的研究规则接入独立月度实验，完成后台运行、同样本 MOM 基线与 MOM-ID 项目对照、独立参考、审核、冻结报告和备份恢复。当前只执行可复算的受控夹具；AI 接口继续留白。原 Alpha101 日度流程保留。

## 使用工作台

1. 启动说明见仓库 README。打开工作台，进入「研究规则」，选择项目约定，检查 MOM/ID 窗口、跳过月和缺失规则，保存规则版本。论文原文模式保留未决项，会得到 blocked 结果。
2. 进入「月度实验」，选择刚保存的规则。默认目标月份 2025-01 至 2025-06；可改成连续 1–24 个月。成本 bps 是目标权重变化的代理成本，默认 0。数据始终是虚构工作日日历和日收益，不是对应日期的市场行情。
3. 确认配置后提交。后台单 worker 公平处理原日度任务与月度任务；页面显示准备、执行、核验与发布状态。完成流水线不意味着研究通过，需分别查看计算状态和参考核验。
4. 查看两策略指标及逐月明细。展开形成权重、信号三分组、九格、持有期标签及缺失日期。缺少标签时保留原持仓并显示不可用，不按事后收益是否存在重新选股。
5. 根据实际观察写审核理由。审核绑定确切尝试和结果摘要；自动化示例明确标记 automation。冻结报告后可下载 JSON/Markdown，后续审核不改变旧报告。
6. 刷新或丢响应后，用页面保留的原请求确认结果。失败、中断、已开始后取消的尝试可明确重试，总计最多三次；首次执行前取消则重新提交新实验。旧尝试和日志保留。

状态轮询只读状态，不重复核验全部文件。「完整核验并刷新月度结果」会检查文件清单、摘要、冻结输入、参考计算及报告一致性；核验失败隐藏旧结果。修改窗口或配置必须新建实验，不覆盖旧产物。

## 可运行的完整示例

使用已安装完整 web 依赖的环境，每次指定新目录：

```bash
.venv/bin/python scripts/demo_v014.py --out artifacts/my-monthly-example
```

示例在临时端口启动真实 API 与 worker，创建项目规则与六个月实验，成本 5 bps；核验独立参考、提交自动化审核、冻结报告，再添加后续记录证明旧报告不变。停服务后离线备份、恢复到新目录并再次验证。不会写入日常工作区。

产物包括 `protocol.json`、`experiment.json`、`report.json`、`report.md`、HTTP 摘要轨迹、服务日志、`result.json`，以及 workspace/backup/restored。workspace 的 `monthly/<experiment>/attempts/<attempt>/output/` 中保留 input/result/reference/environment/report、源码副本和完整 SHA256 清单。

对任一输出目录执行：

```bash
.venv/bin/python -m paper_alpha.monthly_workflow verify /absolute/path/to/output
```

如需重算，将该目录的 `input.json` 作为输入，指定不存在的新目录：

```bash
.venv/bin/python -m paper_alpha.monthly_workflow run /absolute/path/to/input.json --out artifacts/my-monthly-replay
```

## 比较口径

MOM 基线是高动量 +0.5、低动量 −0.5；MOM-ID 对照是低 ID 的动量差减高 ID 的动量差，四个角各 ±0.25。两者总绝对权重均为 1，净权重为 0。这里的 MOM × ID 表示双维度分组，不是把两个信号数值直接相乘。形成样本共享，九格另以多头等权诊断。所有定义是明确的项目比较约定，并非已复现论文完整投资流程。

并列值不拆组，必要角为空时不给替代结果。收益标签只在形成后读取，要求持有月声明日历完整覆盖；不填零，不前向填充。成本根据连续目标权重的绝对变化估算，忽略持仓漂移、借券、融资和滑点。净值只在连续可用月复合，缺月后不重新拼接完整曲线。gross、net、换手分别保存有效月份分母。

独立参考使用 Fraction 复合、独立排名/分组/标签/权重/汇总逻辑，不能证明真实数据、论文忠实性或交易有效性。固定测试覆盖未决规则、并列、缺失、空组、时间边界及未来扰动；HTTP 示例验证工程闭环。真实行情、真实人工流程对照、最终保留测试与跨论文泛化仍未完成。
