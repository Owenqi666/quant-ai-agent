## 本轮工作包

### A：等价观察行与保留区间（Agent lineage）

独占：新增 observation identity 核心/存储模块、research_guard.py 与其 schema、专项测试、scripts/demo_v019_lineage.py、docs/v019_observation_identity.md。不修改 service.py、db.py、API、运行工作区。

- 仅针对已通过现有 synthetic 日频 loader 的完整 date×asset OHLCV 行，用固定字段顺序及引擎 float64 的精确表示生成版本化摘要，不用 epsilon/四舍五入。
- 字段语义和资产日期键进入身份；source/title/version 声明不能授予豁免。索引按 dataset 生成一次，按原文件与登记摘要绑定，随后流式核验。
- 同日不同资产排序、CRLF/引号和等价数字表示共享身份；裁剪/追加/资产子集按实际共享行日期检查，不能整体连通全部日期。
- 原字节 guard 与历史业务 revisions 保持权威；旧索引缺失/篡改不得静默重建后放行。迁移加性生成或记录 unresolved。
- 给 root 提供 SCHEMA 与 seed/migration helper。状态投影显示相关数据的边界，旧 frozen Case 不回填。
- 不能声称识别资产改名、数值变化、所有信息重叠或不同来源等价；不会替真实数据认证。

### B：跨路径有界作业（Agent execution）

独占：domain_research_jobs.py/schema、新辅助模块、monthly_experiments.py、monthly_runner.py、专项测试、scripts/demo_v019_domains.py、docs/v019_domain_execution.md。

- 请求闭合区分 monthly_fixture（协议 ID/digest/config）与 author_study_diagnostic（study ID/digest），只接受枚举动作及原预算，不接受路径、网络、Python 或审批字段。
- 冻结来源、配置和效果键，按 validate→submit→observe→complete 执行月度原队列；作者 study 只验证原输出并保留方法未决/数据不足停止原因，不创建收益实验。
- 复用原月度计算器；父任务总墙钟包含等待，预算约束 claim、supervisor 和 publish，禁止靠删提交步骤解除预算绑定。
- 丢失响应/进程中断原键恢复，只产生一次队列效果；预算闭合后仅一条安全停止记录。不能取消其他 attempt。
- 修复月度 finish 验证失败可能留在 running 的路径，终态 failed 保留文件。
- 新服务导出 SCHEMA、typed models 和 get/list/create/advance/markdown。原 daily ResearchJobs 和旧月度请求不改；无父任务的原月度路径仍可用。

### C：材料语义标注（Agent evidence）

独占：核心 semantic_materials/validation、新 server semantic_annotations/schema、scripts/confirm_v018_semantics.py 的兼容重用、专项测试、scripts/demo_v019_semantics.py、docs/v019_semantic_materials.md。

- 固定已有材料、原模板和来源；读取时验证材料和白名单源，不接受任意文件路径。
- 实际人工提交 reviewer/time/material/hash/case_id 和全部五维结论理由；无需填写原实验审核才能标注独立材料，但不能因此批准实验或新 claim。
- 自动化记录单独计数。无人工数据时语义率为 null/pending；参考判断是未经确认草稿，基础页面默认折叠，表单无默认 passed。
- 保存不可变记录及耐久幂等收据；修改通过显式取代链保留历史，拒绝跨材料/错版本/伪审批/未来时间/缺理由与篡改。
- 新功能不修改原 semantic_cases、旧 CLI 产物、cases、claims 或人工审核。保持旧 CLI 输入/输出兼容。

### D：集成、验收与交付（主 Agent）

独占：db.py/schema15、backup supported versions、API、生成 OpenAPI/TS、基础前端、根级 HTTP/E2E、scripts/demo_v019.py、check_v019_upgrade.py、发布/便携包脚本、版本和 README。

- 所有新表加性注册，先安装 A/B/C schema 再按 A 约定生成历史索引。共享接口变更须先通知主 Agent。
- 在原「研究执行」接入基础跨路径入口；新「语义评测」显示材料、出处、无默认选择的五维表单和历史。加入 workspace/selection 过期响应防线及原键恢复，避免跨任务写入。
- 用真实 worker 接通月度夹具示例，与同冻结输入固定流程完整结果一致；展示作者阻断和材料自动化测试记录，不代替用户标注。
- 三包交叉审核后固定源码，完整 Python/前端/Chrome 和发布验收、独立目录便携安装。
- 用仍在运行的已验收 v0.18 软件备份原工作区；先克隆迁移，保留全部旧业务/摘要/文件，再以验收包升级当前 8765 工作台。迁移时阻止 API/worker 写入，完成后检查实际运行代码/资产身份。

## 必要验收

1. 重编码/裁剪/追加复用保留行拒绝；时间不交叉的共享行不误阻断；改数值/改资产名仍明确覆盖边界。索引和原 authority 被删除/篡改时拒绝。
2. 月度真实计算与相同条件固定流程一致；方法未决、作者样本不足/即使筛查通过仍缺方法均不执行收益。排队/运行/发布超时及预算/提交绑定损坏不登记成功。
3. 并发和丢失响应不会重复提交、重复标注、增加预算；中断/取消保留准确尝试身份和失败文件。
4. 材料与源引用可查，用户判断无默认值；自动化不成为人类标签或批准，真实 human=0 时汇总无质量成绩。
5. schema14→15 加性迁移和备份恢复，原 Case、工具账本、claims、实验、审核和历史文件不改，原版本流程继续通过。

## 完成标准和不能代办的部分

本轮交付的是上述三个尚缺的工程连接处。需要真实人工判断、真实可用数据、供应商和远端仓库的信息不伪造；软件完成后分别列出准确剩余项及用户下一步。不中途以“计划完成”代替实现，不以夹具成绩宣称投资收益、论文复现、AI 优势或研究耗时改善。
