# 行业组合 MOM-only 开发案例

用户选择了“先完成行业组合 MOM 演示”。本例将论文已知的十一月动量信号应用到 Kenneth French 的 49 个预计算美国行业组合；资产、三分组、行业间等权、持有定义、样本门槛与日期均明确标为项目修改。它不复现原论文的国际个股或 MOM+ID/Table8 方法。

## 本机启动与检查

在项目根目录执行一条命令即可，来源摘要和固定配置由工具读取，不需要手填：

```sh
.venv/bin/python scripts/demo_mom_only.py --out artifacts/my-mom-only-demo
```

`--out` 必须是新目录；重复运行请换目录，已完成和失败的尝试都保留。该示例不调用网络，只使用本轮已核验下载的本地原 ZIP、下载收据、原论文及作者脚本；新克隆不会自动拥有这些 Git 忽略的第三方资料。若本地缺少，先提供与合同一致的固定来源资料，不用最新版文件静默替换。

完成后打开 `artifacts/my-mom-only-demo/report.md`，查看实际数值及其范围。逐月信号、形成排除原因、持有标签、固定权重、候选与基线指标在 `result.json`；转换单位与缺值原因在 `diagnostics.json`。

只读复核：

```sh
.venv/bin/python -m paper_alpha.mom_only_workflow verify --out artifacts/my-mom-only-demo
```

`verify` 会重新核对原 ZIP 字节与限定月份转换、原 PDF 具体页码/文字位置、作者脚本摘要、独立数值参考、全部产物清单与报告。它不写原目录，不执行被保存的 MATLAB，不产生人工认可。

## 固定方法与时间

- 数据：官方 49 Industry Portfolios 的月度 Value Weighted 区块。这里 VW 是原行业内部的股票权重；项目在行业组合之间再分配权重。
- 来源版本：下载时前言为 `202608 CRSP database`，原 ZIP SHA256 固定为 `16b3f20bf5bd1db8f5cd7a1b29f5cab1350eb0d5106c5309f77a6629590b1c0e`。
- 输入：2009-01..2011-12 共 36 个自然月。按固定源合同将百分数除以 100；先识别 `-99.99` / `-999` 缺值码。直接官方 49 页未单独写百分数单位，来源评估保留该证据限制。
- 开发：2010-01..2011-12，共 24 月。对目标月 H，MOM 只复合 H−12..H−2 的十一项收益，跳过 H−1；历史必须完整，无填补、无压缩缺月。
- 样本：形成时至少 30 个行业组合，是本研究的项目门槛。49 个行业系列不是原作者匿名个股行，不会解除原 30 行 / 166 月计划的阻断。
- 候选：同值中位名次三分组，不拆并列值；最高组等权合计 +0.5，最低组合计 −0.5，目标毛敞口 1、净敞口 0。
- 基线：同一形成样本的行业等权多头，毛敞口 1、净敞口 1。基线与候选风险敞口不同，差值不能解释成风险调整后的 Alpha 优势。
- 标签：固定形成权重后才读取 H 的月收益。缺持有标签不反向删除资产或重新配权；当月结果缺失，累计路径不跨缺月拼接。
- 范围：只计算毛收益，没有费用、借券、融资、成交或可交易篮子模型；年化均值/波动率假设无风险收益为零，不混称为含实际无风险收益的 Sharpe。
- 保留：2012-01..2013-12 的数值不解析或评价。完整原 ZIP 和 member 摘要包含后期字节；当前资料是事后修订历史，不能称当年可得数据或完全盲测。

窗口、日期、来源、资产轴、方法证据和配置在本例版本内固定。改字段、日期或方法需要明确新研究合同和版本；不能靠重算 JSON 摘要或将保留期改个名字绕过约束。

附加单位检查只读取 2009 Q1 四个行业的官方日度与月度记录：`/100` 解释在预定舍入误差包络内匹配 10/12 项，直接按小数解释为 0/12；两项未匹配保留，没有调整参数。它是有限的一致性支持，不能替代官方单位声明或证明月日序列全等。详见 [单位核对](../artifacts/mom-only-source-assessment-01/unit-check-01/notes.md)。

## 产物与恢复

每次输出保存 `invocation.json`、输入文件、环境、计算代码快照、原论文和作者脚本、面板、结果、独立参考、报告、状态及文件摘要。`state.json` 记录单次尝试和阶段；无效源或方法也保留调用请求与失败原因。失败或中断不在同一目录重跑，原尝试继续留存，新目录用于新的尝试。

保存的 `source/` 含执行代码、方法和配置。可用同一解释器运行保存代码复现到另一新目录：切换当前目录到原输出的 `source/`，用原解释器的绝对路径调用 `-B -m paper_alpha.mom_only_workflow run`，显式提供原输出 `inputs/source.zip`、其摘要、`inputs/source_receipt.json`、`inputs/config.json`、`inputs/method.json`，并用 `--evidence-dir` 指向原 `inputs/`。输入、输出均使用绝对路径。`-B` 必须保留：防止 Python 在冻结源码中生成字节码，完整性核验会拒绝任何额外文件。这只使用既有本地文件，不重新下载可变化的历史；不要在原仓库目录只设置 `PYTHONPATH` 后冒充运行了快照代码。

报告只格式化计算工具的结果。人工判断、模型质量、人工流程耗时仍为空；选择研究范围不会自动成为质量标注。新 CLI 没有写入当前工作台或迁移数据库，现有 8765 应用继续运行原验收包。
