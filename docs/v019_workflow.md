# v0.19 使用与验证

本轮保持基础前端和关闭的 AI 接口，补齐数据复用保护、月度父任务预算和固定材料标注。启动安装仍按 README；同一工作区只运行一个 launcher。默认新目录为 var/workbench，本机历史目录是 var/v09-workbench，不能混淆。

## 固定论文材料的人工标注

1. 左侧选择「语义评测」，选择一项材料。页面显示提案、引文、页码/定位和可打开的固定来源。
2. 阅读原文及提案后，为五个维度分别选择自己的判断并写理由。未评定/不适用也要说明理由；默认空白不会自动通过。未经人工确认的参考提示默认折叠，可选择查看，不能作为独立真值。
3. 明确选择「本人实际阅读后的判断」或「自动化测试记录」，填写审核者和实际确认时间（含时区）。审核者是本地声明，不是身份认证；程序不能代用户选择 human。
4. 点击「预检材料标注」，核对身份和全部判断，再「保存自己的材料标注」。服务保留材料与标注摘要、耐久提交收据和时间。此标签不批准实验或结构化结论。
5. 响应丢失时点击「安全重试材料标注提交」。刷新后原请求和此材料的本机草稿仍可检查；不会自动提交或自动恢复草稿。保存成功后下载记录并查看历史。
6. 修改旧判断时显式填写最新原标注 ID，再预检/保存。必须保持同材料、同声明来源和同审核者；历史不会改写，不同审核者的分歧会显式保留。

原材料 `semantic_cases.json` 继续保持原 pending 状态；新声明保存在工作区标注账本。自动化与人工分开汇总。没有实际人工数据时仍 pending/质量成绩 null；人工覆盖不是模型准确率，也不是经软件证明的语义真值。旧 batch CLI `confirm_v018_semantics.py` 继续可用，其独立产物不自动进入工作区标签。

## 月度与作者准入的受控执行

1. 在「研究规则」保存明确的项目规则版本，或在「研究准入」导入已有作者诊断。
2. 左侧选择「研究执行」，展开「创建一次跨路径研究执行」。选择月度项目约定或作者准入，再选择准确来源版本。
3. 月度路径可设置开发开始/结束月、最小资产数和成本代理。配置不能解除原文未决规则，输入仍是服务器生成的 controlled_fixture。作者准入路径只核验诊断，不创建组合收益。
4. 创建受控领域执行后按可用按钮依次校验、提交、核对、完成。月度使用原队列与 worker；状态轮询不消耗执行步骤。作者条件不足或方法未解决会保留阻断。
5. 查看本次月度实际输出或作者诊断，在原结果页检查图表、结果与限制；需要时用现有研究任务入口关联精确来源。终态后下载领域执行记录。

默认最多12步、2次技术失败和创建起算300秒，含手工推进、排队、计算和发布等待。刷新不重置预算。预算闭合后仅另允许一条安全停止记录，取消绑定准确 attempt。响应丢失使用原键安全重试，不另建实验。这里的月度项目定义和收益/净值代理不等于作者方法、真实行情、投资回测或论文复现。

## 数据表示改变时的保护

原 CSV 字节保护继续存在。新索引使用已通过原 loader 的完整 date×asset×OHLCV 浮点观察行。合法引号/CRLF/数值编码变化、同日资产重排、裁剪、追加和资产子集中的完全相同行，在实际保护日期继续受约束；不会把所有相关数据日期整体视作一个区间。

数据值或资产名变化未被此精确行保护覆盖，不由此取得“未曾看过”的研究资格。来源、公司行动、点时股票池和所有信息重叠仍需专门审查。当前日频数据路径仍只支持 synthetic；作者 MAT 的来源核验与月度协议另有独立语义。

```bash
.venv/bin/python scripts/demo_v019.py --out artifacts/my-v019-example
.venv/bin/python scripts/export_api_contract.py --check
.venv/bin/python scripts/verify_release.py --out artifacts/my-v019-release --browser-channel chrome

  --backup artifacts/my-frozen-schema14-backup --out artifacts/my-v019-clone-upgrade
```

组合示例包含三个独立工作区：完全相同行的时间保护、实际月度队列及同条件固定基线、仅 automation 的材料标注与恢复。失败/阻断示例和来源摘要保留。示例不会写真实 human 标签，也不报告模型费用、人工时间收益或市场收益成果。原 v0.18 示例和固定规则评测继续进入完整发布门禁。
