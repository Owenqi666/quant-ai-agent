# v0.10：可选的引导式流程记录

## 与日常研究分开

日常研究只需要：选择研究 → 查看或编辑论文依据和候选 → 提交实验 → 审核一次 → 查看报告。流程观测是比较使用过程的可选工具；不填写观测、不计时，也可以正常研究。

AI、RAG、BRAIN 自动调用仍未接入。本页记录用户实际操作，不能据此把合成测试或浏览器自动化写成人工研究成果。

## 第一次记录

1. 选择与固定协议相符的单候选 Alpha101 研究，进入「流程观测」。不兼容时显示原因并禁止开始。
2. 在「开始流程记录」填写参与者标识、熟悉程度，选择工作台或手动 CLI，确认执行顺序和停止条件。默认是练习；正式对照要在开始前关闭练习。
3. 新草稿首次载入服务环境；可核验的发布包代码提交会一并填入。恢复草稿和已经填写的共同条件不会被刷新覆盖。若代码身份缺失，在「版本、环境和允许工具」确认一次提交标识。CLI 实际使用其他环境时必须修改为实际信息，不能沿用不符的声明。
4. 点击「开始本次记录」，阅读阶段开始主动计时。参与者、环境、停止条件、修订和协议在该次会话中冻结。

记录的是本人的实际过程；最后保存仍需明确确认来源。不会自动填入已完成或审核通过。

## 六阶段操作

阶段分别为阅读、假设、实现、配置与运行、审核、报告。点击阶段按钮结束原来的区间；已有计时会转为新阶段的主动时间。暂停状态下切阶段只改变阶段，不生成区间。

- 主动工作：点击「开始主动计时」。
- 等待程序：点击「等待工具」。
- 暂时离开：点击「暂时离开」。
- 不记录当前时段：点击「暂停流程计时」。

在工作台其他页面，紧凑记录条仍可切换阶段、暂停、恢复、等待或离开。它不会根据页面名字推断正在做哪一步；切到 PDF 或终端也不会自动判为离开。

同一会话只有一个当前区间，每次切换都先结束旧区间。审核页面会在全流程记录开启期间隐藏独立的审核计时器，不需复制时间或重新填写审核结论。

## 结束和结果绑定

1. 完成操作后点「结束本次记录」。正在计时的区间由本次点击明确结束。
2. 选择已完成、未完成或放弃。后两者填写原因；失败和部分过程也可保留。
3. 工作台路径：从列表选择本次实验、执行尝试和已保存的本人分项审核。只列同参与者的人工审核，必须自己选择；系统据此填入准确的运行、修订、尝试、审核标识，复用五维判断。结果只有选择具体执行尝试后才检查完整性。运行中的尝试不能绑定为不可变结果，可等待结束或明确不绑定尝试后保存未完成记录。
4. 手动 CLI 路径：展开命令说明，一次复制同一固定任务的运行与核验命令。填写实际外部输出目录、核验依据和报告位置，并完成一次五维判断。外部位置只是文本声明，后端不会读取任意本机路径。
5. 「检查并准备保存」调用既有服务预检。核对计算耗时与绑定情况，在一处确认实际来源和不可变保存后提交。

缺失阶段保持未测量，不补零。完成记录需要实际结果、核验依据、报告和五维判断；判断可以未通过，但没有检查的项目不能算已完成。

保存后共用条件继续保留，表单切换到另一条路径并递增执行顺序。第二次执行的学习效应、实际使用的模板和获得的帮助，仍需如实填写。两条路径不符合可比条件时，汇总保留原因而不生成耗时差。

## 恢复、并发和原始数据

草稿保存在当前浏览器，按工作区和研究隔离。每次有效变更先验证可恢复格式、确认本机写入，再应用到页面。

- 明确暂停后刷新：恢复已结束区间，可以继续；刷新期间不补时间。
- 未暂停就刷新、关闭或切换研究：开放区间改为中断，结束时间为 null。旧协议将未知结束视为占用本次会话剩余时段，因此该会话只能结束并保存为未完成或放弃，然后开始新的会话；不猜补结束时间、不继续累加。
- 切换普通工作台模块：组件保留，当前计时继续，紧凑条可操作。
- 提交响应丢失：完整请求、幂等键与引导草稿快照已经持久保存，刷新后使用原请求重试。
- 确认保存后的清理同时核对会话和完整提交快照，在删除恢复请求前处理。旧提交不能清掉同会话的新修改；其他标签页修改后的草稿也不会被覆盖。
- 草稿损坏或存储不可写：保留原数据并阻止覆盖；不静默重置。浏览器本机草稿不等于服务端备份。

JSON 导入和原始模板放在「高级：JSON 导入与原始模板」。既有脚本、自动化记录、列表、原始导出和服务汇总接口保持可用。高级导入不会仅凭相同会话标识清理引导草稿。

## 验证范围

定向单测检查阶段计时、暂停、时钟异常、刷新中断、作用域隔离、精确提交快照清理及不可恢复草稿拒写。浏览器场景检查无 JSON 的基础表单、跨模块记录、暂停与活动状态刷新、待确认请求的快照恢复和新旧草稿隔离。

引导浏览器验收只到人工来源记录的只读预检，或拦截并中止发送；不保存模拟的人工观测。自动化来源的真实导入、响应丢失后的幂等回放和汇总排除规则由原导入测试验证。以上是软件验证，不是研究耗时提升结果。

当前代码与环境、参与者身份、外部 CLI 引用仍有声明性质；单个熟悉材料的对照不能推断普遍效率提升。固定协议仍用于合成行情上的开发流程，最终测试区间继续锁定。
