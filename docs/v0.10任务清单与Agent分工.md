# v0.10 操作流程简化：任务、分工与验收

起点：v0.9.0 / 9dcbd3885ffd23e551ef70cc77913174281f04eb。用户反馈手填 JSON、内部 ID、复制审核和计时过于复杂。本轮保留基础前端，简化交互与关联，不新增 AI、RAG、BRAIN 或真实行情执行能力。

## 产品目标

日常研究只需确认候选、运行、审核一次、查看报告。人工对照是可选评测，不是研究或开发的前置条件。协议、实验身份、可核验的版本和结果引用由系统维护；真实人工判断、工作状态与未完成原因仍由本人提供。高级 JSON 入口保留，普通用户无需使用。

## 并行任务与边界

| ID | 负责人 | 写入范围 | 交付与验收 |
|---|---|---|---|
| S1 | 日常研究 Agent | App、QualityPanel、ResearchReviewForm、ResearchInsights、专属组件/测试/说明 | 明确主流程入口；从选定结果直接审核/报告；不自动选错版本或把未审核记为通过 |
| S2 | 观测 UI Agent | WorkflowObservations、新引导表单、计时/草稿 helper、专属测试/说明 | 默认表单；自动 ID/摘要；一次填写共同条件；显式计时跨页面、恢复不补造；结束预检与可靠保存 |
| S3 | 上下文后端 Agent | 新 observation_context 与 schema、专属测试/说明 | 只读协议兼容性、限定运行/尝试/审核选择、精确绑定与版本/环境来源；不创建人工记录 |
| S4 | 主 Agent | API 接入、生成契约、源码包出处、版本、发布检查、集成文档 | 契约一致；实际运行代码身份不误取宿主 Git；统一验收、迁移预览与历史保留 |
| S5 | 全组交叉复核 | 仅审查他人模块，修改归原负责人 | 保存/刷新/迟到响应、计时中断、旧任务不兼容、审核复用、发布环境、基础可用性 |

共享接口：WorkflowObservations 在研究作用域内常驻，visible 控制页面主体，onOpen 返回可选观测页，onRecordingChange 表明有未结束会话（含暂停）；切页面不卸载，切研究不把计时串到其他研究。

后端新增 GET workflow-observation-context，只读且不默认选择历史结果。提交仍走原有 validate/create 路径，schema 7、冻结协议和已保存观测保持不变。上下文返回的来源与限制可查看，不能把服务环境冒充人工身份验证。

## 验收重点

1. 日常从现有研究到报告不需要填写观测或 JSON；明确选择实验后才执行写操作。
2. 引导记录由本人开始、切换阶段/等待/离开、结束；单一区间不重叠。不用页面隐藏推断离开，不用引擎日志推断人工工时。
3. 跨页记录保持；刷新/切研究后未结束区间保留中断与缺失，不能用恢复时间补终点。已结束区间和待提交原请求耐久保存。
4. 工作台结果使用确切修订/run/attempt/review；只有本人选择匹配的既有审核才复用五维内容，不生成判断。CLI 外部引用仍是声明。
5. 同一对照的共同条件可以明确复用，实际差异不能被自动覆盖。练习默认开启，人工来源需本人确认；测试样例不进入真实人工样本。
6. 当前协议仅适用于固定单候选 Alpha101。其他研究显示不兼容原因，不暗改任务。
7. 正常结束可预检并保存一次；响应丢失用原键确认；不能由于刷新/并发产生重复观测或报告。
8. 运行环境从当前服务/已核验快照取得。Git commit 缺来源时留空需一次声明，不能在嵌套发布包调用 git 向上拿到开发仓库 HEAD。
9. 高级导入、历史导出和原恢复入口可用；此前数据、自动化记录和冻结协议不改写。
10. 定向测试与跨模块复核后冻结源码，统一验收；预览使用已验收包；本轮 schema 不变，先离线备份再保留原工作区路径启动，以保留浏览器草稿作用域。旧源码包和备份保留。

## 顺序与交付

任务计划 → 三 Agent 并行 → 主 Agent 集成 → 交叉复核 → 源码冻结与统一验收 → 更新本地预览 → 简短用户操作说明。

S1–S4 实现已完成，S5 交叉复核发现的草稿误清理与恢复格式边界问题已修复。日常流程和引导观测使用独立测试工作区，未向实际工作台写入模拟人工记录。源码冻结后再运行统一验收，通过后才升级实际预览。

最终验收、实际测试数、版本摘要、运行升级及保留的失败记录以新的 artifacts/release-v010-* 交付记录为准，不将自动化验收等同于人工使用效果。
