## 研究问题与证据

研究问题：在过去收益相近时，持续的小幅价格变化与少数跳涨跳跌，是否对应不同的后续动量？论文使用信息离散度 ID 研究这一机制；低 ID 对应较连续的信息代理。它是价格构造的代理变量，不直接观测新闻，也不能单凭统计关系证明因果机制。

| 依据 | PDF 页码 | 印刷页码 | 用途 |
|---|---|---|---|
| §2.2 | 4 | 244 | 普通动量的月份定义 |
| §2.3、脚注 11、式 2 | 5–6 | 245–246 | ID 定义及取值时点 |
| §6、Table 8 | 23–25 | 263–265 | 按 ID 和动量分组的对照 |
| Data availability | 30 | 270 | 原始数据库和公开数据的限制 |

首轮只准备两个实验定义：普通动量基线，以及 ID 条件下的动量组合；独立排序作为主对照，顺序排序作为后续稳健性检查。不是简单“做多低 ID 股票”，也不把 ID 直接乘进原动量表达式。数学定义和未决项保存在同目录的 `research_spec.json`。

## 已发现的实现问题

作者代码 `SetupDataA.m` 和 `Table8B.m` 显示：若目标收益月为 t，MOM 使用 t−12 至 t−2，ID 数据列取 t−1。公开包直接读取预计算的 DGW，未包含其每日构造过程，尚不能确认内部窗口、缺值和最少有效日数。不能将 ID 与 MOM 自动设为同一窗口，也不能把其他指标的 100 日门槛移植过来。

Table 8 表注将独立排序与顺序排序都写成 Panel B；正文、表内标题与作者两份脚本支持 A 为独立排序、B 为顺序排序。此处记录歧义，不让提取器自行猜测。

原始行情来自受许可数据库；公开包包含扰动或删减的数据，不能用于验证论文市场收益数值。其脚本还引用了当前 V2 文件清单未提供的 `Intnl_WCMonthly.mat`。本次留存了六份小型脚本供阅读和移植参考，没有执行它们，也没有下载大型市场数据包。

## 下一轮实施顺序

以下是本项目的工程设计，尚未实施或得到用户的研究判断。

1. **先冻结研究语义。** 补齐 ID 构造和数据覆盖规则；确认不了就保留阻断项。若采用自行定义的窗口、股票池、权重或缺失处理，生成独立的修改版本，不能标为原式复现。
2. **实现月度独立参考。** 用可手算的小样本检查跨月边界、跳月、零收益、缺失、并列值、空组和权重。主流程与参考程序必须独立实现；修改未来数据不得改变已形成的信号。
3. **接一个明确行情来源。** 核对日/月收益、历史资产标识、公司行动、月末市值和当时可得的成员资格；记录快照和使用范围。普通收盘价不能静默替代含分红收益，当前股票名单不能当历史股票池。
4. **扩展现有评估工具。** 当前引擎只接受合成 OHLCV，使用下一开盘到再下一开盘的日度标签。需新增月度研究契约、分组组合及覆盖记录，不能把月度论文硬套进现有日度收益图。继续复用队列、任务保存、摘要、审核和报告。
5. **冻结开发协议后运行。** 基线与候选共享数据、期间、样本资格和成本口径。先在 validation 迭代；test 继续锁定。报告分组收益、相对基线差异、覆盖、排除原因和不确定性；净收益必须另有费用与交易假设。成功标准是计算与证据一致，不要求收益为正。

真实数据来源及研究语义确定后，由数据 Agent 负责适配，评估 Agent 负责独立参考，主 Agent 负责契约、集成和验收。现在不并行编写几个各自假设窗口的计算版本。
