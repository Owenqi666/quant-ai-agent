# 独立 MOM-only 方法证据与项目修改

日期：2026-10-05。对应 [方法证据合同](mom_only_contract.json)。本文件整理当前本地论文和作者代码的出处，另列可执行示例拟采用的项目选择；它不是作者组合实验的复制配置，也不是人工审核结果。

## 可直接继承的信号定义

令 H 为目标收益月，原始月动量为：

```text
MOM(i,H) = prod(1 + Return(i,m), m = H-12..H-2) - 1
```

这是 **11 个自然月**，明确跳过 H-1。H=2010-01 时，使用 2009-01..2009-11，跳过 2009-12，2010-01 的收益仅作为之后的持有标签。不能把缺失月份删除后取“最近十一项”，不能把自然月换成固定交易日数，也不能把当前月收益用于形成资格。

出处分别有不同作用：

| 固定论文 PDF p.4，印刷 p.244，§2.2 | 目标月用 H-12..H-2，并定义原论文的国家中性化、十分位、市值加权 WML 和月度调仓 | 本轮核对字节、提取文字并实际查看完整页图 |
| 固定论文 PDF p.24，印刷 p.264，Table 8 | 十一个月且跳过最近月；双排序、国家中性化和月调仓 | 本轮复验原月份锚点并实际查看完整页图 |

论文 PDF SHA256 为 `07b8dad425b23328588a9668e8fccb58f18f79a4d1665d8fc49680198b0fbc2e`。原 PDF 保持不变；本轮只渲染 p.4、p.6、p.24 和 p.30。[自动核对产物](../../artifacts/mom-only-method-01/) 包含来源摘要、锚点复验和页图。正文中的归因是来源事实核对，不是对经济解释的人工认可。

## 严格缺失政策及其归属

原 MOM 月窗口和作者乘积公式有明确出处。以下输入保护属于本项目明确的工程/研究政策：十一项均须为有限的十进制简单收益、不得低于 -1，复合结果须为有限可表示值；整月或单资产字段缺失均不填补、不压缩月轴。一个实际 -1 的收益允许进入乘积，得到 -1；缺值不能当作 -1 或 0。

作者代码没有使用忽略 NaN 的乘积，且后续资格检查需要有限 `R11_t`，因此跳过缺值继续复合与当前作者代码不一致。但项目对非法单位、低于 -1、数值溢出和诊断原因的规则，不应冒称为论文完整的数据清洗规范。普通收盘价、超额收益和含分红简单收益也不能未经声明互换。

独立 MOM-only 的**信号计算**不需要 DGW 或市值；如果组合选择市值加权、历史个股资格或与 MOM+ID 做同样本比较，则仍需要对应字段。没有 DGW 不会阻断已定义的 MOM 公式，也不能据此说完整 Table 8 已可执行。
