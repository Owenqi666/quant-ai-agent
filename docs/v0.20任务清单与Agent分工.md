## 执行顺序与分工

### A：ClaimReviews（Agent lineage）

独占 `paper_alpha/server/claim_reviews.py`、`claim_reviews_schema.py`、专项测试、`scripts/demo_v020_claim_reviews.py`、`docs/v020_claim_reviews.md`。

- 复用 ResearchClaims、ResearchCases 和既有五维模型，不修改旧 claim payload、状态、Case 或结果审核。
- target 由服务端生成：claims ID/digest、批次内 claim ID/准确摘要、Case 和原 source 摘要、对应 evidence/metric refs 和工具值、冻结执行/数据/方法来源；创建前携准确 target_digest。
- 人工身份是本地声明；automation 记录独立。全部维度需显式理由，无默认通过。不能提交自造数值、审批布尔或 provenance。
- 追加式审核与耐久幂等；准确旧记录摘要的取代链，同 scope 防止分叉/时间倒退，不同人工审核者的冲突显式显示。
- 每次读取复验原始 claim/Case，提交最后核验；未知源、错摘要、源篡改安全拒绝。
- new-dir demo 只创建 automation，人工分支用隔离合成测试，实际 human=0。

### B：SemanticEvaluationSets（Agent evidence）

独占 `paper_alpha/semantic_evaluation.py`、`paper_alpha/server/semantic_evaluation_sets.py`、`semantic_evaluation_sets_schema.py`、导出/离线核验脚本、`scripts/demo_v020_semantic_sets.py`、专项测试和 `docs/v020_semantic_evaluation.md`。

- 冻结准确材料摘要、选定案例及所有活动人工声明；请求携准确预期 annotation IDs/digests。不能静默挑选某个审核者以隐藏冲突。
- 每案例每维度保留 eligible/pending/unknown/conflicting；automation 仅审计附件。新增或取代标注不改旧参考快照。
- 结果核对绑定准确 set ID/digest、case 和五维声明及执行来源；明确匹配数、可比较数、总维度数和不可比较原因。无人工参考时比较率为空；模型质量一直为空。
- 导出冻结快照、原材料和白名单来源摘要，并独立离线核验；不能接受任意路径的 HTTP 读取，不能把开发材料宣称独立最终测试集。
- 不修改 v018 固定工程评测、原材料、旧 CLI 或六阶段流程观测协议。

### C：ResearchBindings（Agent execution）

独占 `paper_alpha/research_binding.py`、`paper_alpha/server/research_bindings.py`、`research_bindings_schema.py`、本地准备/核验脚本、`scripts/demo_v020_bindings.py`、专项测试和 `docs/v020_research_binding.md`。

- 精确绑定既有 selected paper、协议 ID/digest、固定作者来源版本/摘要、预声明 plan、scan/result 摘要、已有 panel/study，以及源专属窗口/缺失规则与证据。
- 复用作者数据审计/扫描核验及准入计算，声明核验与实际原 MAT 当次核验分开；HTTP 不打开 MAT、不联网、不启动收益计算。
- 协议 project convention 与论文规则、DGW 和 holding 未决事项明确保留。扫描成功不授予执行许可；当前数据不足且方法未决时稳定 blocked。
- 合同不可变、幂等、每次读取复验精确关联资源；源/协议/扫描版本不相容拒绝，不将独立 panel 自动提升为全源扫描证明。
- new-dir portable demo 用明确夹具；本地实际 MAT 核验另存来源证据，不能要求便携包分发大文件或未经许可论文文件。

## 验收条件

- 准确审核版本不能被旧结果审批、材料标注或自动化记录替代；分叉、外部取代、错版本、伪造字段和源篡改拒绝。
- 参考快照准确固定全部活动声明和 conflict/unknown；改变标注只产生新版本，不回写旧版；导出附件与结果核对能复验。
- 研究绑定把论文/协议/实际来源/预声明扫描及准入一一对应；实际不充分数据和未决方法保留 blocked，无伪造收益或论文复现。
- 幂等收据、并发、丢响应和最终来源核验完成；不可变数据被删除/篡改时不能靠重建放行。
- schema15→16 加性升级不改变历史业务、设置、迁移记录、文件和已冻结摘要。便携安装不依赖当前 var 或大 MAT。
- 没有真实人工观测、模型调用、远端 CI 时不产生对应成果数字；完整 UI 设计仍后置。
