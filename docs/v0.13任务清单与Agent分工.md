# v0.13 时间窗口与缺失规则优化

本轮解决研究规则的两类歧义：论文定义与用户参数修改的关系；缺失日期、缺失收益及有效零收益的处理。沿用审核、明确契约、分 Agent 实施、交叉检查、冻结验收、备份更新的工作流。AI 留白，界面沿用基础设计。

## 审核结论

- 原日度引擎具有严格的合成 OHLCV 契约，不能将月度规则作为无效配置挂在旧实验上。
- 当前 momentum 材料只处于准备态。MOM 的十一自然月与跳一月可确认；ID 内部日频构造仍未完整公开。
- 需要分别保留论文未决状态与可计算的项目约定。项目默认采用明确同窗、完整交易日收益、零值计入且不填补的定义，并允许派生有说明的窗口及覆盖规则变体。
- 首轮交付规则保存、日期展开和信号/覆盖诊断；不包含真实行情接入、组合收益或净值回测。界面和报告须明确这一边界。
