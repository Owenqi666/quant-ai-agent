# 月度研究的真实数据来源调查

调查日期：2026-10-03。目的：接通一个有明确字段与时间规则的真实来源，不先扩展任意格式导入。当前代码仍仅接受 controlled_fixture。以下是官方页面核对后的候选说明，不表示用户已有账号、数据已下载、许可已确认或适配已实现。

## 适配所需的最小输入

本项目的 MOM/ID 需要单个证券的日度总收益、独立交易日历和可解释的上市/覆盖起点。须明确调整价格是否包括分红与拆股；单纯收盘价不能直接标为 total return。还需要证券身份、历史股票池、退市覆盖、数据版本及抓取时间。没有 point-in-time 股票池时只能声明固定样本研究，不能声称无幸存者偏差。

| 候选 | 官方可确认信息 | 本项目结论 |
|---|---|---|
| SimFin | 免费档列出 API、批量下载及五年历史；官方字段定义区分 Adj. Close（拆股与分红调整）与 Close（拆股调整、不含分红） | 可作为一个明确来源继续评估。实际导出、覆盖、日历、退市和使用范围未验证，不能直接接通或宣称永久归档/再分发权利。 |
| Kenneth French Data Library | 提供因子和组合收益，包含 momentum 组合 | 可作为未来外部汇总参照；不能直接替代构建单股 ID 所需的证券级日收益。此适用性结论来自其公开数据层级。 |
| Nasdaq WIKI Prices | 官方描述为约 3000 家美国公司的公开领域价格/分红/拆股数据；明确自 2018-04-11 起不再积极支持 | 不作为近期研究的首选行情源。历史软件实验另行说明范围；不能套到近年样本。 |

官方依据：[SimFin 价格及使用问答](https://www.simfin.com/en/prices/)、[SimFin 支持说明](https://www.simfin.com/en/support/)、[官方 Python 字段定义](https://github.com/SimFin/simfin/blob/master/simfin/names.py)、[French 数据库](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)、[Nasdaq WIKI](https://data.nasdaq.com/databases/WIKIP)。网页内容可能更新，真正导入前要核对所用文件和当时规则。SimFin 的免费账户不等于无限制授权，页面还有取消后的数据清理说明，需核对实际账户条款与用户用途。

## 下一步的单源验收

1. 用户给出已有可用文件/平台权限及用途；若没有，再选择具体免费来源和可用导出。这里不代用户注册或接受条款。
2. 固定原始文件 SHA256、获取时间、来源说明、字段版本；确认许可证对本地研究、缓存、实验归档的范围。
3. 编写该来源专属转换器：证券标识与日期规范化、调整后总收益、独立日历、覆盖起点；保留原始到规范化行的映射。价格缺日导致跨期收益时必须标记，不能伪装成单日收益。
4. 先审查重复行、非有限值、无效价格、公司行动、缺日、上市前缺失和退市覆盖。声明源文件缺失与市场休市的区别。
5. 在固定小样本手工复算并与来源校对，再允许月度引擎使用一个新的真实数据契约版本。不要只把 controlled_fixture 字符串改名就通过准入。
6. 冻结开发/验证/最终测试区间，先在验证区间研究。保留最终测试前置批准、一次性执行和冻结结果的实现仍是后续任务。

当前最关键的外部缺口是可实际使用的单源文件及数据语义；此文完成来源调查与适配要求，没有把真实数据适配标为已完成。
