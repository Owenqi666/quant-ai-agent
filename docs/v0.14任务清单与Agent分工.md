# v0.14 月度研究实验闭环

按 v0.13 审核结论推进：先接通研究规则与正式实验，再实现月度组合与同样本对照，准备一个真实来源，补独立数值验证和有明确口径的绩效诊断。AI/RAG、BRAIN、整体 UI 重设计仍后置。

## 审核与本轮交付

已有规则窗口、MOM/PRET/ID 信号诊断、不可变规则记录及 CLI 重算。旧 Task/worker 仅识别合成 OHLCV 日度实验；不能向旧 Task 添加不执行的 protocol_id，也不能将日度 t+1/t+2 评估当作月度收益。

本轮交付独立、版本化月度实验：保存规则引用与完整快照、固定候选定义、目标月份、受控数据、后台尝试、同样本 MOM 与 MOM×ID 对照、独立数值参考、审核和冻结报告。复用单工作区维护锁、单 worker 进程锁、请求恢复、备份和源码发布机制。旧 Alpha101 路径保留。

真实行情需要确定来源及使用范围，已向用户询问；来源调查与适配设计可并行进行，不能用未经确认的价格、幸存股票池或许可声明冒充已接通。最终 test 的正式执行依赖真实来源、冻结候选及未披露区间，继续保持隔离，不因新增月度模块开放任意 test 开关。
