## 边界和验收终点

- 原工作区不新增自动冒充人工的审核或流程观测。
- 实际作者数据仍不足，DGW/持有等方法仍未决；本轮只核验和保留阻断，不输出真实组合收益。
- 人工参考、人工耗时和模型质量无真实数据时为空。真实人工操作由用户执行。
- 发布成功必须同时具备全阶段通过、源码不变、独立安装成功、原工作区迁移核对和 live 身份/资产确认。
- 发布收尾以后按人工评测、一个真实行情研究案例、AI、最终 UI 的顺序推进；BRAIN 和远端 CI 各自保留未完成状态。
