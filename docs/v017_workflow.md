# v0.17 研究任务与受限工具流程

## 本轮能做什么

先使用原有模块完成因子计算、受控月度实验或作者数据准入。再到「研究任务」将该具体结果冻结为一项可检查的研究上下文，查看依据、方法、输出、阻塞原因和允许下一步。任务不会把不同数据源或计算方法合并为一份回测结果。

研究任务是现有产物的关联快照。原路径继续负责数据导入、计算、人工审核和修订；本轮没有新建任意论文假设、将作者 MAT 接到组合收益计算或开放最终测试。新 AI 工具链限于诊断与提案，模型接口仍为空。

## 基础页面操作

1. 打开工作台，在左侧选择「研究任务」。
2. 展开「从现有结果建立研究任务」，选择来源与已完成的结果。目录可翻页，不需要手填内部 ID。
3. 系统核验后显示当前状态与数据/方法范围。填写任务名称，点击「保存研究任务关联」。如果核验失败，先回原结果排查，不会用旧输出继续建立任务。
4. 在任务详情检查研究定义、论文或代码依据、项目约定、实际指标及限制。作者准入显示资格计数及未达标原因；不会显示并不存在的收益。
5. 要做人工判断，点击「打开对应结果与人工审核」，跳转到精确原结果。新增审核不自动改写旧任务快照；需要纳入新审核时，重新核验来源并建立新关联。
6. 如需验证未来 Agent 的工具边界，展开「受限工具验证与建议记录」。主动创建会话，再核对上下文、依据或计算结果，选择允许的下一步并保存草稿。

草稿固定标记 automation、draft、语义未审核，不改变筛查门槛、计算结果或人工审核。数据不足的停止建议是有效输出。新增完整来源或论证新方法需要通过原有人工计划修订流程，不能靠工具草稿直接执行。

## 预算和恢复

页面默认每会话最多 8 次调用、2 次失败、30 秒累计调用预算。调用前持久扣除次数；失败记录和重放收据保留。刷新或重启不增加预算，相同请求键重放原调用。预算耗尽后不会自动创建会话；新预算由用户主动分配。模型工具表没有创建会话的能力。

只读核验采用执行前后时间检查，超时结果不发布；中断恢复保守扣除该调用预留的剩余时间。页面显示的是预算计费用时，不是人工研究用时。当前没有 LLM token 或费用结果。

请求响应丢失时，使用页面「安全重试」提交本机保存的原请求。服务器已记账的失败会显示具体错误码，草稿依据保留在原调用请求中。来源失效或记录完整性不通过时，停止该会话并核对原结果；不要通过换会话绕开来源问题。

## 可复现示例与评测

在项目环境执行，输出目录必须是新目录：

```bash
.venv/bin/python scripts/demo_v017.py --out artifacts/my-research-task
.venv/bin/python scripts/evaluate_v017.py --out artifacts/my-research-decisions
```

示例调用现有月度计算工具，产生受控数据的真实计算结果，再与作者准入阻断案例分别关联任务。评测冻结十项工程规则，比较同输入的固定路径和脚本工具路径，保存结果、引用、调用账本及报告。

也可复用之前保存的作者源扫描：

```bash
.venv/bin/python scripts/demo_v017.py \
  --input artifacts/author-studies-v016-01/intnl-mom/input.json \
  --out artifacts/my-source-research-task
```

这只重新核验已有扫描的聚合一致性，不重新扫描原始 MAT。实际文件复算继续使用 v0.16 的 `eligibility_workflow verify --source`。

工程规则预期与待人工确认的研究语义标签分别保存。评测通过不能宣称 LLM 优势、人工提效、市场收益或完整论文复现。详见 [评测说明](v017_evaluation.md)。

## 后续 AI/UI 工作的边界

当前契约可供有限范围的证据读取、结果解释和下一步建议模型使用。接提供商时仍需加入模型输入输出、模型版本、token/费用记录和相同固定任务上的实际模型评测。提案自由文本需要人工语义审核，引用 ID 合法不代表文本忠于原文。

自动生成新研究假设需要在相应路径绑定明确假设与证据；自动推进 Momentum 收益实验需要月度来源适配和固定方法；自动策略迭代还需要研究系列级开发/最终测试限制。这些能力没有通过本轮诊断工具间接开放。

基础页面只展示已有任务状态和结果；完整页面布局、信息架构与视觉设计仍待后续。底层定义参考 [任务契约](v017_case_contract.md)、[受限工具契约](v017_tools.md) 和 [冻结接口](v017_research_contract.md)。
