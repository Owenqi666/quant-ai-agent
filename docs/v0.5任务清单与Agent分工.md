日期：2026-10-01。起点：本地 `v0.4.0` / `6da816d`，工作树干净。
状态：功能、专项测试与独立复核完成，待统一冻结验收；最终勾选、日志和验收结论另存新的 `artifacts/release-v05-*`。

## 目标与范围

让现有确定性研究链路可由基础表单操作、可在独立目录交付，并且接口变更有机器检查。本轮继续使用 React/TypeScript、FastAPI、SQLite WAL 和独立 worker，AI/RAG/BRAIN 保持关闭，前端不做视觉重设计。

用户本轮明确确认使用过《101 Formulaic Alphas》，因此将它作为人工研究流程的开发材料。这项确认只涉及材料选择与使用经历，不等于认可现有全部假设、经济解释、自动测试审核或投资效果。原有 v0.4 冻结任务和实验记录保持原样。

## 并行与文件所有权

1. 契约 agent：`server/api.py`、`schemas.py`、新响应模型、契约生成脚本、`frontend/src/generated/`、契约专项测试/说明。
2. 前端 agent：其余 `frontend/src/`、前端测试和 E2E；先做编辑器，生成契约冻结后接入。不得改后端科学语义。
3. 交付 agent：源码包构建/搬迁验收脚本、原干净安装入口、专项测试和搬迁说明；不触碰统一验收入口。
4. 主 agent：任务文档、只读诊断、研究评测协议、版本和公共文档、统一验收、Git 与交付记录。

业务模块和测试按所有权写入；任何交叉修改先交接。每个 agent 报告实际测试和未做项后冻结，主 agent 才执行正式整体验收。子模块完成不等于版本交付完成。

## 保持的约束

- 原始论文、数据、修订、尝试、审核和结果不原地重写；开发与验收使用独立工作区。
- 响应模型不以大范围 optional/任意 dict 隐藏契约错误；旧版字段差异明确处理。
- 表单不静默替换数据字段或经济假设；数值仍由工具产生，审核由明确操作产生。
- 草稿是浏览器本地工作副本，不作为已保存修订或实验依据。工作区路径身份仅用于本机隔离，不是权限控制。
- 诊断不执行恢复、清理或自动删除；归档沿用完整备份工具，避免破坏引用链。
- 本地搬迁包含已有论文示例，公开再分发许可未确认；不上传远端，也不标为可公开发布包。
- 同篇论文中的公式不能被包装为跨论文独立保留评测；最终市场 test 时间区间仍不解锁。
- 测试条数、重复执行与别名变体不等于独立研究覆盖；不预设 agent 胜过 normalized_fixed。

## 执行顺序

契约与表单、搬迁包独立准备 → 契约冻结接前端 → 专项测试和人工流程整合 → 冻结源码/文档 → 统一验收（新目录） → 保存真实结果、任务状态和本地版本。

性能优化以已有测量和新出现的瓶颈为依据。本轮诊断提供容量可见性，不承诺吞吐提升，不添加新的分布式组件。

## 冻结前交接

- 契约：35 个 JSON 操作绑定响应模型；生成检查通过，历史检查采用明确兼容结构，不改写存量结果。
- 前端：基础表单、草稿、差异、关联选择器；延迟上传、A→B→A 修订响应和短时离线分别保持当前编辑。自动浏览器审核仍声明 automation。
- 交付：已完成独立安装开发验证；首次版本错配失败保留，随后严格匹配包/安装/API 版本并成功启动。最终产物仍需随整体验收重新生成。
- 诊断：独立复核后补 FIFO、目录替换符号链接和坏 heartbeat 故障测试。业务数据只读；活跃 SQLite 协调文件可能变化，文档明确说明。
- 评测：用户确认的 Alpha101 新开发案例固定为一任务、一公式、三策略各两次；人工语义标签与工时仍为空白，不与原四任务开发集去重后相加成新发现。
- 剩余外部条件：真实数据来源/授权/时间规则及远端仓库目标未提供。不会以移除 synthetic 限制或创建未经指定的远端仓库来“完成”这些项。

## 运行切换发现的启动修复

第一次冻结验收 `release-v05-01` 的 14 步全部通过；随后切换本地预览时，立即重启被端口预检拒绝。独立临时 TCP 端口复现了旧连接 TIME_WAIT 导致裸 bind 失败，而 SO_REUSEADDR 允许重启。修复只调整端口预检，与服务端正常重启语义一致，仍拒绝实际监听者，不启用 SO_REUSEPORT、不停止未知程序。此改动及专项测试需要新交付目录重新验收；原失败日志和备份继续保留。

## 已有浏览器状态的迁移检查

`release-v05-02` 的 14 步验收通过，启动和实际 worker 执行成功。随后在用户既有浏览器中发现全局 `paper-alpha-research` 仍可指向其他工作区的旧研究，导致 404 后停留在读取状态。新增按工作区恢复选择、真实详情核验、仅对 404 回退和可重试错误；不能因为不在第一页就丢弃合法历史研究，短时健康检查失败也不能重置编辑。该缺口与自动浏览器的干净上下文不同，保留现场记录，修复后再次冻结验收。
