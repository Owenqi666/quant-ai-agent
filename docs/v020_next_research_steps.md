# v0.20 发布后的研究操作清单

8765 已完成 v0.20 / schema16 正式升级，记录在 `artifacts/release-v020-03/delivery.json`。先打开 [工作台](http://127.0.0.1:8765/)，确认 [健康状态](http://127.0.0.1:8765/api/health) 和 worker 在线。原文“尚待验收升级”是发布前快照；用户不手动修改数据库。

新增的 [行业组合 MOM-only 案例](v020_mom_only_workflow.md) 使用独立 CLI 接通公开组合收益的开发实验，明确标为项目修改；它没有改写下面的原作者数据阻断，也没有写入现行工作台。

当前本轮实际人工标注、准确结论审核及正式六阶段观测为 0；自动化测试没有代填。首轮顺序是：一项人工材料判断 → 一条准确结论审核 → 冻结小型参考集 → 可选的两路径流程观测。真实行情研究另设准入门槛。

## 1. 最短人工语义评测

1. 进入「语义评测」，在「选择语义评测材料」选 `alpha101_formula`。阅读「待判断的提案」「引用依据」，点击「打开来源 alpha101_paper」核对原 PDF 的公式和页码。参考提示未经人工确认，不作为答案。
2. 「标注声明来源」选「本人实际阅读后的判断」，填写自己的审核者标识，点击「记录当前确认时间」。逐项填写五个判断及理由：引用与页码、假设忠实度、经济解释归因、字段含义、实现一致性。未判断或不适用如实选择并说明；不要求全部通过。
3. 点击「预检材料标注」→「保存自己的材料标注」→下载本次记录。摘要、材料版本和提交键由系统关联，不用填写 hash 或 JSON。
4. 进入「研究任务」，优先打开与单候选 Alpha101 冻结结果对应的任务，在「带实际数值引用的结论草稿」打开已有草稿。没有草稿时，保留预填的指标路径，仅填写自己的解释文字，再点「核对实际指标引用」→「保存已核对的结论草稿」。日度默认路径指向第一候选；多候选结果不能默认把它当作 Alpha101。缺少相应任务或正确引用时，由工具从已有核验结果准备，用户不手填指标路径、hash 或 JSON，原实验保留。
5. 在「审核这一次的结论文字」选择具体结论。核对同页的实际工具值、原文、数据及方法范围，在「填写本版本的五维判断」明确本人来源、标识、实际时间和理由，预检后保存。材料标注不会替代这次准确文字的审核；通用实验“接受”也不会替代它。
6. 返回「语义评测」，展开「选择材料并冻结参考集」，首轮只勾选已经检查的 `alpha101_formula`，点「预览本次参考快照」→「冻结本次参考版本」→「下载参考集与核对记录」。全部活动人工声明自动纳入，其他未标注材料无需为凑覆盖率填写。

**首轮终点：**一份本人材料标注、一份绑定准确文字版本的本人 ClaimReview、一份含该材料的冻结参考集及下载文件。保留 failed、unknown 和冲突也算完成真实审核；不把它们改成 passed。参考集的可比较维度数用于检查参考是否可用，`semantic_quality_score` 仍为空。

本轮无需进入「导入结构化结果核对」或手写核对 JSON。以后确有另一组完整声明需要比较时，由工具绑定该准确参考版本并转换输入，真人核对声明来源和判断；一致性率不作为模型质量或研究正确率。

## 2. 可选：六阶段人工流程对照

此项回答使用流程是否省时；不是日常研究的前置条件，也不是上述语义标注的计时替代。先做一次练习，正式对照只做同一人、同一任务的两条记录，不先预设工作台更快。

1. 在「研究项目」或「切换研究」选择符合 `evaluation_suites/v05/task.json` 的**单候选 Alpha101**研究，进入「流程观测」。普通「导入示例研究」包含三个候选，不能直接作为该协议的对照。若提示不兼容，先由工具用固定文件准备独立的单候选研究；用户无需拼写任务 JSON，原研究不覆盖。
2. 填参与者标识、熟悉程度、停止条件、执行顺序和允许工具，选择「工作台」或「手动 CLI」。先保留「练习记录」熟悉入口；正式开始前关闭练习，并冻结两路径的共同条件。本人分项审核与参与者使用同一标识。
3. 确认服务预填的版本及环境。由工具确认 CLI 使用已验收包的实际解释器和同一依赖；不能把开发目录 `.venv` 默认当作正在运行的发布环境。一般无需抄录代码 hash；无法自动确认的条件才如实补充。
4. 点「开始本次记录」，按实际活动切换六阶段：

| 页面阶段 | 本人操作 | 工具负责 |
|---|---|---|
| 阅读 | 核对原文、页码和证据 | 展示固定 PDF、来源与引用 |
| 假设 | 判断公式、信号方向及解释归因 | 保存结构化定义和版本 |
| 实现 | 检查候选是否表达所选假设 | 校验字段、算子及表达式 |
| 配置与运行 | 确认固定数据、验证区间和预算 | 计算并保留尝试及核验结果 |
| 审核 | 看着实际输出填写本人五维判断及理由 | 展示执行公式、指标和原文，绑定冻结结果 |
| 报告 | 核对报告数字与实际产物，整理出处 | 生成冻结报告和可下载记录 |

5. 工作台路径沿用「确认候选 → 运行 → 审核 → 报告」，执行方式选「规范化固定流程」。程序运行时点「等待工具」，继续阅读/编辑时恢复「开始主动计时」，休息点「暂时离开」。切页不会自动识别阶段；看 PDF 或使用终端仍可能是主动工作。
6. 手动路径在同一观测页展开「CLI 操作命令」并复制生成命令，使用同一固定任务及 `normalized_fixed`。实际阅读、整理假设、核验和报告也要完成；命令成功不替代这些工作。两路径均可正常使用同一文档，记录实际模板复用、帮助和学习效应。
7. 点「结束本次记录」，如实选已完成、未完成或放弃。工作台路径从列表选本次实验、执行尝试和**本人的分项研究审核**，系统复用五维判断；不是选择 ClaimReview 或材料标签。手动路径填实际输出目录、核验依据、报告位置及本人五维判断。外部位置只保存为声明，后台不会读取路径冒充核验。
8. 点「检查并准备保存」，核对预检，勾选「确认来源与不可变保存」后点「确认导入不可变观测」。共同条件保留后再做另一条路径。最后点「计算观测汇总」，导出两份原记录。

**对照终点：**两份真实、非练习记录及服务端汇总。仅在同协议、任务、数据、版本、环境与允许工具相符，且两路径六阶段主动区间完整时，解释该个案的耗时差。失败、放弃和返工照常保存；缺测不填零。活动计时中刷新/关闭导致中断时，保存未完成记录再开新会话，不猜补结束时间。缺比较条件时，终点是明确不可比较的原因，而不是一个效率数字。

详细规则以 [引导记录说明](v010_guided_observation.md) 和固定 `evaluation_suites/v07/human_protocol.json` 为准。旧 v0.7 说明中“仅审核有计时器”已被引导式六阶段记录更新。

## 3. 真实行情研究：先达到准入条件，再计算

已有 GJS Momentum 论文和作者文件可用于证据与诊断。作者 MAT 经扰动和随机删除；当前选定来源的预声明扫描不足，DGW 日频内部窗口、缺失政策及完整 universe/分组/中性化/持有权重/标签方法仍未决。paper 名称、下载到 MAT、数量检查通过或 ResearchBinding 保存成功，都不能替代可执行的数据与方法条件。

| 顺序 | 必须由本人决定或提供 | 可由工具完成及有限终点 |
|---|---|---|
| 1. 冻结一个研究问题 | 完整论文方法，或明确归因为本人改动的 MOM-only 小假设；确认研究的市场与样本范围 | 整理出处、公式、原文规则和未决事项。方法未决则保留 blocked |
| 2. 确定一个实际数据源 | 文件/可访问来源、使用授权范围及字段说明；不能只提供 paper 名称 | 盘点实际证券标识、月份/交易日、回报/价格、复权、缺失、上市退市范围和字段可得时间，保存数据版本 |
| 3. 明确时间与执行语义 | 原文明确规则与项目选择分别确认；预声明开发/保留区间、缺失政策、样本门槛、成本和持有定义 | 核对形成时点、MOM 窗口及未来标签隔离。不用月度预计算 DGW 冒充完整日频序列 |
| 4. 针对该来源适配 | 判断替代字段是否改变原假设；改变时另建假设/版本 | 实施一个窄来源转换与质量校验，复用现有计算、队列、记录和报告。当前普通数据入口仍只接受 synthetic，月度收益入口仍是受控夹具；真实行情执行适配尚需工程实现 |
| 5. 准入后执行一个实验 | 看实际样本与规则是否满足原计划；不足时决定补数据或停止 | 通过独立数值参考与时序扰动检查后，先在开发验证区间执行同样本 MOM 基线及明确候选。保留最终区间，报告精确配置、失败和实际结果 |
| 6. 审核并冻结 | 本人检查研究忠实度、数据限制与结果解释 | 保存准确结论审核、冻结报告和来源记录。指标由计算工具产生，不以图形观感代替检查 |

已有作者研究记录可在升级后的「研究准入」→打开记录→「连接论文、规则与本次作者扫描」中选择实际论文与已有协议，填写标题，点「核对论文规则与来源」→「保存准确来源绑定」。服务自动派生所有摘要与 panel 引用。如果日常工作区没有这些原记录，由工具核验并导入已有 artifact；不要手填 hash 或复制某个夹具当成实际来源。

已完成的独立真实来源准备见 `artifacts/v020-author-source-01/attempt-02`。其中当前原 MAT 字节和有界 panel 原始重抽已核验，旧 166 月 scan 的 artifact 已核验，**本次没有重新扫描全源计数**；诊断仍为 DATA_INSUFFICIENT。它不等于日常工作区已自动导入，也不等于真实行情实验。绑定外的 Domain/Case 关联保存于本地 receipt，不能解锁收益。

**真实研究终点：**先交付一份可检查的数据/方法准入决定。条件不满足时，准确来源、缺口、阻断和停止记录就是本阶段完成；条件满足后再交付一个验证区间实验、同样本基线、独立核对与本人审核报告。未满足前不降低既有门槛、不填补作者删减值、不触碰保留测试，也不制造收益。AI 接口、完整 UI 设计和 BRAIN 均不属于此清单。
