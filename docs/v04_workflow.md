# v0.4 数据与审核回流

本版继续采用基础 React 页面、FastAPI、SQLite WAL 与 Python worker。AI、RAG、BRAIN 和真实行情入口关闭。发布结论、测试计数及机器实测耗时保存在新建的 `artifacts/release-v04-*/`，历史 v0.3 产物保持原样。

## 1. 从新数据开始

启动方法见仓库 README。在页面的新建研究区上传 `tests/fixtures/datasets/market.csv` 和 `metadata.json`，保存返回的导入 ID。第二份 fixture 有独立生成记录，96 个合成工作日、7 个资产、种子 20261001；不是旧数据改名。

1. 上传只保存不可变字节与收据，不自动登记数据。
2. 点击验证，检查报告的检查项、规则码、输入/验证器/报告摘要与限制。断网后用导入 ID 查询，不盲目重复上传。
3. 成功报告只证明受控数据契约通过。质量检查沿用引擎 loader，遇到首个错误停止；`detected_error_count` 不是整个文件错误总数，没有坐标时不虚构定位。
4. 点击登记，提交绑定该输入及验证报告的幂等请求；相同科学内容返回已有数据版本，不覆盖原目录或标题。
5. 选择登记版本，并确认日期区间。第二份示例的 train 为 2024-01-02 至 2024-02-14，validation 为 2024-02-15 至 2024-03-29，test 为 2024-04-01 至 2024-05-14。`min_assets=5`。
6. 可复制当前研究任务创建新研究；数据变化不自动改写字段、公式或假设。一个研究固定绑定一个数据版本。

CSV 上限 16 MiB，元信息 2 MiB，合计另有 64 KiB multipart 开销，网格上限 100,000。单次验证子进程限时 30 秒，同一工作空间最多一个。元信息必须声明 synthetic、生成方式、日历、资产、时点、价格处理与文件摘要。禁止任意服务器路径、自动修正摘要、自动补值或把 close 当作 VWAP。

研究预检拒绝不合法的整体时间切分或 min_assets；候选缺字段、窗口不足、别名与非法表达式则显示明确预检结果并保留原任务。这样负例仍能进入实验记录，由引擎逐候选拒绝或阻断；预检通过本身不证明结果有效。

## 2. 审核、修订与关闭问题

审核绑定 run、attempt、candidate 和结果摘要；来源是声明值，不是认证身份。页面默认为 human，自动验收必须选择 automation；旧记录为 legacy_unknown。

从审核创建问题后，用追加事件记录 open → proposed → awaiting_review → resolved，或 deferred 并填写原因。每次操作携带幂等键与最新事件 ID；页面过期时重新读取，不覆盖别人的后续判断。

- implementation_fix：保持研究/数据身份，链接目标修订、具体实验与其通过的原审核案例。只检查相关案例，其他候选的无关失败不替代本问题的证明。
- hypothesis_change / data_change / accept_limitation：显式记录不同处理方式，链接经过验证的目标实验；不计入“同条件实现修复”。
- 后端冻结目标 attempt 和结果摘要；目标以后重试不改变关闭时的证据。系统不会因一次实验通过自动生成积极审核或关闭问题。

汇总将重复审核按唯一输出去重，将尝试数量与独立 run 分开；自动样例不增加人工审核覆盖。JSON 导出保存参与统计的记录、条件、版本和摘要，可用 `aggregate_feedback(**report['inputs'])` 重算。CSV 保存比例分子、分母与记录 ID；完整审计以 JSON 为准。审核至关闭耗时包含等待，不代表人工工时或节省时间。

## 3. 日志与历史目录

新事件页使用全局数据库 ID，保持固定 high_watermark，不能使用单次引擎 attempt 的 engine_sequence 充当游标。实时缓存最多 1,000 条，每轮最多 4 页；缓存淘汰会明确提示，完整历史可单独分页访问。终态补齐后以低频刷新发现审核与新尝试。

历史目录支持研究、数据、候选及适用的状态/类别/来源过滤。追加边界固定；可变状态在后续刷新中可能变化。工作区展示窗口与目录分页都不等于服务器只有这些记录。

## 4. 固定任务集与独立参考

```sh
.venv/bin/python -m paper_alpha suite --manifest evaluation_suites/v04/manifest.json --out artifacts/my-v04-suite
.venv/bin/python scripts/demo_v04.py --out artifacts/my-v04-flow
```

每个输出目录必须不存在。任务集固定 3 条策略 fixed / normalized_fixed / agent（有界规则修复），默认两次重复，全部使用相同预声明预算。任务与候选是不同分母；重复运行不增加独立研究任务。`acceptance_passed` 表示符合清单预期，`fully_covered` 另行表示数值参考覆盖，二者不能混用。

新增参考仅限 Alpha012 和去掉一次幂后的 Alpha033；后者明确属于 user_modification。Alpha006/101 原有参考继续保留。不支持的合法表达式仍为 not_comparable。保留任务目前是 pending 人工材料的锁定占位，没有执行，不算已有独立研究测试集。所有已调试工程变体归开发集，金融 test 时间区间也继续锁定。

个人研究材料、人工忠实度判断、实际工作耗时、模型费用和真实市场效果尚缺，报告不补造数字。完整验证产出、引用命中、数值覆盖和一致率分别报告；缺失、未运行和异常保留在预声明分母。

## 5. 交付与运行范围

`scripts/verify_release.py` 串行执行测试、浏览器、基线、任务集、HTTP回流恢复与新虚拟环境安装。业务源码与测试文档冻结后执行；引擎发现源码快照期间有改动会拒绝混合版本。不能在多 agent 同时写代码时将失败快照当作正式验收。

本地 Git 使用现有身份记录版本；尚未指定远端目标，所以没有推送、公开论文或执行远端 CI。本版不宣称公网可用、多用户认证、有效 Alpha 发现或个人独立完成比例。个人贡献确认后再参考 `docs/resume_evidence.md` 写 SWE 经历。
